## 2. 유지하는 결정

- 12-01 목표는 조건부 제한 실거래 시험이다. 수익성 입증이나 자동 실전 승격의 결정이 아니다.
- F0 비용은 월 0원이라는 운영자 진술로 완료했다. 같은 증빙을 반복 요구하지 않는다.
- STAGE_1 등록과 SID 203 생성은 완료 이력이다. 재생성하거나 기준 행을 초기화하지 않는다.
- 본 시험의 WF false 예외와 maxHoldHours=0 결정을 다른 전략·세션에 일반화하지 않는다.
- 기존 66세션의 중간 성과 비열람·T0·판정 기준을 유지한다.
- 실거래 위험 한도·증액/재개 금지·시작/중단/56일 종료는 [현재 계획 §4](LIMITED_LIVE_TEST_PLAN.md#4-제한-실거래-시험의-고정-조건)와 [실행 절차](LIMITED_LIVE_TEST_RUNBOOK.md)를 따른다.
