## 3. R13 — 비용 스트레스 (상태와 남은 선택지)

### 3-1. 무엇이 막혀 있는가

- 검증 §4(나)는 스트레스(슬리피지 0.2%×2) 열에서 평균 순수익 > 0 · 거래당 순수익률 > 0 을 요구한다.
- 그리고 "엔진을 다시 실행한다. 사후 차감이 아니다" 라고 정했다(`SUPERTREND_VALIDATION_PREREG.md` §2).
- 66세션은 0.1% 로만 돈다. 그래서 지금 설계로는 스트레스가 NA 이고, 주 비용을 모두 통과해도 "미확정 유지 · 실전 진입 불가" 다.

### 3-2. 재현 가능성 — 엄밀 재현은 불가능

| 확인한 것 | 결과 | 근거 |
|---|---|---|
| 모의 엔진이 청산에 쓰는 가격 | 진행 중인 H1 봉의 최신 종가를 60초마다 읽는다. 신호는 닫힌 봉으로 평가하지만, 손절·익절·시간 초과 청산과 매수 체결 기준가는 그 분 단위 가격이다 | `PaperTradingService.java:625`, `:702`, `:725` |
| 그 분 단위 가격이 남는가 | **남지 않는다** — 캐시는 봉마다 한 행을 덮어쓴다(upsert) | `MarketDataUpsertService` |
| 백테스트로 같은 시스템을 다시 돌릴 수 있는가 | 같은 시스템이 아니다 — 다음 봉 시가 체결, 손절·익절은 봉 고가·저가 판단 | `BacktestEngine.java:113`, `:156-176` |

### 3-3. 사후 차감 — 참고 분석 (판정 근거 아님)

역사적 검사 출력(22코인 × 3팔). 매수 수수료 누락(R4)을 **입력에서 바로잡은 뒤** 비교했다. 스크립트: `scripts/supertrend_filter/posthoc_vs_rerun.py`.

| 팔 | 근사 오차(MAIN 왕복 합 − MAIN 요약) | 평균 순수익 사후 / 재실행 / 차이 | 거래당 순수익률 사후 / 재실행 / 차이 | 코인별 차이 최소 / 최대 / 평균 절대값 |
|---|---|---|---|---|
| A | ≤ 0.005%p | +12.077 / +11.955 / **+0.122** | +0.4614 / +0.4384 / +0.0230 | −13.94 / +28.17 / 5.44 %p |
| B | ≤ 0.005%p | +13.162 / +13.110 / **+0.051** | +0.4550 / +0.4409 / +0.0142 | −14.66 / +34.94 / 6.02 %p |
| OFF | ≤ 0.005%p | +11.424 / +11.823 / **−0.398** | +0.3386 / +0.3201 / +0.0185 | −12.59 / +18.68 / 5.02 %p |

- 수수료를 보정하면 MAIN 왕복 합이 MAIN 요약과 같다. 그래서 **남는 차이는 비용에 따라 거래 경로가 달라지는 효과**다.
- 평균의 차이는 부호가 팔마다 다르다(+0.12 ~ −0.40). 코인별로는 ±35%p 까지 어긋난다.
- 🔴 이 세 결과의 최대 차이를 전향 모의 엔진 오차의 상한으로 볼 근거는 없다. 기간이 짧다고 보수적이라고 할 수도 없다. **초안 1 의 보정폭(+2.2%p · +0.03%p)과 그 근거는 철회한다.**
- 참고: 검증 문서의 역사적 결과 표(스트레스 거래당 +0.4884%)도 같은 누락을 안고 있다. 수정은 R4 범위이며, 이번에는 이 참고 분석의 입력만 바로잡았다.
