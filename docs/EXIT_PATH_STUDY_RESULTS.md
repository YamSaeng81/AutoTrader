## 2. 격자 결과 — 60칸 전부 비관 경계 음수

```
a ∈ {0.5,1,2,3,5}%  ×  b ∈ {1,2,3,5}%  ×  H ∈ {24,48,72}봉,  비용 0.30%
```

| 경계 분류 | 칸 수 |
|---|---|
| 양쪽 경계 > 0 (**후보 자격**) | **0** |
| 양쪽 경계 ≤ 0 (**낙관 경계까지 비양수**) | **30** |
| 비관 < 0 < 낙관 (**판정 불가**) | **30** |

비관 경계 최선값은 `H=24, a=5%, b=3%` 의 **−0.40%**, 최악은 `a=0.5%, b=5%` 의 **−2.65%**.
낙관 경계 최선값은 `a=5%, b=1%` 의 **+1.86%**.

목표 도달률 자체는 낮지 않다 — `a=1%` 에서 47~54%, `a=2%` 에서 48~55%(H=72).
그런데도 비관 경계가 전부 음수인 것은 **손절 선도달과 불명이 그만큼 많기 때문**이다.

### 위약 후보 발생률 (§5.3)

```
위약 탐색 200회 × 60칸 × 선정 절차 전체  →  후보 발생 0회  (발생률 0.000)
```

🔴 **이 수치를 '절차가 적절히 작동한다'는 근거로 읽으면 안 된다.**
위약의 불명률이 실제보다 2~3배 낮다(§4). 즉 **실제와 위약의 관측 조건이 달랐다.**
따라서 이 0회는 실제 탐색의 우연성을 **같은 조건에서 잰 것이 아니다.**

⚠️ 불명이 적은 쪽이 후보를 내기 더 쉽다고 단정할 수도 없다 — 해상도가 높아지면
손실이 **더 분명해질** 수도 있다. 방향을 추정하지 않고 **조건이 달랐다는 한계까지만** 기록한다.

## 3. 🔴 가장 큰 한계 — 불명 30칸

불명(순서 알 수 없음)의 출처를 분해하면:

| 출처 | 비율 |
|---|---|
| **시작봉 불명** (진입이 봉 중간이라 그 봉의 고·저에 진입 전 움직임이 섞임) | **6.0 ~ 59.4%** |
| 봉내 동시접촉 (한 봉에서 목표·손절 모두 접촉) | 0.0 ~ 1.9% |

**거의 전부가 시작봉 불명이다.** 진입 시각 오프셋은 중앙값 약 1분이지만,
가장 짧은 가용 주기가 M15(74.7%) 또는 H1(25.3%) 이라 그 1분 안의 순서를 알 수 없다.
`a` 가 작을수록(목표가 가까울수록) 시작봉이 이미 목표가를 스쳤을 확률이 커져 불명이 는다.

🔴 그래서 **30칸은 "손실"이 아니라 "모름"이다.** 비관 경계가 음수인 것은
불명을 전부 손절로 간주했기 때문이며, 낙관 경계에서는 양수다.
**M1 캔들이 있으면 해소된다 — 현재 DB에는 M15·H1 만 있다.**

## 4. 🔴 ⑥ 위약 진입 대비는 결론을 내지 못한다

최초 구현에 결함이 있었다: 위약 진입을 H1 봉 **시가**에 정렬해 뽑아
위약에는 시작봉 불명이 아예 생기지 않았다. 실제만 불명 패널티를 받은 불공정 비교였다.

봉 내 오프셋 분포를 실제와 맞춰 다시 쟀는데도 불명 비율이 여전히 벌어진다:

| | 실제 | 위약(정합) |
|---|---|---|
| `a=2%, b=2%` 불명 | 24.8% | 9.7% |
| `a=5%, b=3%` 불명 | 12.0% | 3.0% |

전략 진입이 **변동성이 큰 순간에 들어가기 때문**으로 보인다(진입 봉이 목표·손절을 걸칠 확률이 높다).
이건 인공물이 아니라 실제 성질이지만, 그만큼 비관 경계가 실제 쪽을 더 깎는다.

결과도 경계에 따라 갈린다:

| 경계 | 실제가 위약보다 나은 칸 |
|---|---|
| 비관 | **0 / 20** (평균 −0.50%p) |
| 낙관 | **14 / 20** (평균 +0.12%p) |

🔴 **두 경계가 반대 방향이므로 ⑥ 은 결론이 아니다.**
"전략 진입이 무작위 진입보다 나빴다"고 읽어서는 안 된다.

## 5. 이 결과가 뜻하는 것

**뜻하는 것**
- 검사한 진입 집합(DYN_PAPER 442건)과 청산 격자(60칸)에서, **새 자료에서 검증할 만한 목표·손절 규칙 후보가 나오지 않았다**
- 30칸은 **이 관측 표본과 체결 가정에서 낙관 경계까지 비양수**였다 — 목표가 작을수록
  (a ≤ 1%) 비용 0.30% 에 눌린다. 🔴 **미래 기대수익이 음수라고 확정한 것이 아니다**

**뜻하지 않는 것**
- 🔴 "경로 기반 청산에 기대수익이 없다" — 30칸은 데이터 해상도 때문에 **모르는 것**이다
- 🔴 "전략 진입이 무작위보다 나쁘다" — §4 참조, 경계가 갈린다
- 🔴 프로젝트 종료 근거 — 이건 **검사한 진입·격자 한 쌍**에 대한 결과다

**남아 있는 구체적 질문**
1. **M1 캔들을 수집하면** 30칸의 판정 불가가 해소된다. 비용은 수집 기간뿐이다
2. 6주·특정 국면 표본이다. 같은 격자를 더 긴 기간에 적용할 수 있다
3. `SUPERTREND` 상위봉 필터의 **걸러내는 능력**은 여전히 측정된 적이 없다
