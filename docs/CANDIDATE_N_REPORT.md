## 0. 결론

**이 후보는 "N 산정 불가"로 종료한다(§3 종료 기준).** 고정한 비교 기준(BTC 보유)에 대해 개발 자료가 양의 IR 을 뒷받침하지 않는다. 그래서 N 을 계산할 타당한 IR 가정이 없다.

- 개발 자료(2022-12-26 종가 ~ 2026-09-22, 3.74년)의 비용 차감 IR 은 **−0.95**(주 비용)다. 부트스트랩 90% 구간은 −1.97 ~ −0.04 이고, IR ≤ 0 인 비율은 95.8% 다. 스트레스 비용도 같다(§4).
- 의존성 D 는 1.04(Newey–West)·1.13(부트스트랩)로 1 에 가깝다. N 이 정의되지 않는 이유는 D 가 아니라 IR 의 부호다.
- **이 후보에 대해서만** 말한다. 다른 후보나 12월 전체가 불가능하다는 뜻이 아니다(§6). 다만 이 후보로는 12월 실운영 경로를 확보하지 못했다.
- 이 결과는 **개발 자료 한 구간(강세장 2023~2024 포함)**에서 나왔다. 미래에 IR 이 음수라는 판정이 아니다. 양의 IR 을 가정할 근거를 자료에서 얻지 못했다는 뜻이다.

## 3. 평가 규칙 — 계산 전 고정

이 절과 [`scripts/candidate_n/btc_donchian_n.py`](../scripts/candidate_n/btc_donchian_n.py)를 **계산하기 전에 커밋**한다. 결과를 본 뒤 바꾸지 않는다.

| 항목 | 고정 내용 |
|---|---|
| 자료 | 업비트 공개 시세 KRW-BTC 일봉(`/v1/candles/days`, UTC 00:00 시작). 시작일 2022-01-01 ~ 2026-09-21. 마지막 봉은 2026-09-22 00:00 UTC 에 끝난다. 이미 열람한 개발 구간(`VALIDATION_FIT_REVIEW.md` §3) 안이다. 상장 ~ 2021-12-30 구간과 2026-09-22 이후는 쓰지 않는다. 응답 본문을 그대로 저장하고, 기존 H1 개발 자료의 23:00 UTC 봉 종가와 대조한다 |
| 준비 구간 | 360일 룩백·90일 변동성이 모두 유효해지는 날(자료 360번째 종가)까지는 성과를 세지 않는다. 준비에도 2022-01-01 이전 자료는 쓰지 않는다 |
| 체결 시각 | t일 종가(UTC 00:00 경계)로 신호·비중을 계산하고, **그 종가 직후에 체결**한다(업비트는 24시간 거래라 다음 봉 시가 ≈ t일 종가). 보유 비중은 t+1일 종가까지의 수익률에 적용한다. 가격 차이는 슬리피지 비용으로 대신한다 |
| 비용 | 두 비용 팔(TSMOM 제안서 §4 ⑨ 그대로). **주 비용** = 수수료 0.05% + 슬리피지 0.1%(편도 0.15%), **스트레스** = 0.05% + 0.2%(편도 0.25%). 매일 회전량(가격 변동으로 흘러간 비중과 목표 비중의 차이)에 편도 비용을 곱해 뺀다. 비교 기준에도 같은 비용(시작 매수 1회)을 뺀다. 비용 0 은 논문 표 1과 규모를 비교하는 참고용으로만 계산한다 |
| 평가 대상 | 일별 **전략 − BTC 보유** 순수익률 e_t |
| 정보비율 | IR = 평균(e) ÷ 표준편차(e) × √365 |
| 의존성 D | e 의 장기 분산 ÷ 표본 분산. Newey–West(바틀렛 가중, 지연 = ⌊4·(n/100)^(2/9)⌋). D < 1 도 그대로 쓴다. 정상 블록 부트스트랩으로 구한 평균의 분산 비율을 대조값으로 함께 적는다 |
| 불확실성 | IR 의 정상 블록 부트스트랩(평균 블록 20일, 5,000회, 시드 20261029) 5%·50%·95% 분위와 IR ≤ 0 비율 |
| 필요 기간 | N(년) = ((z₁₋α + z₁₋β) ÷ IR)² × D. IR 은 점추정·부트 95%·부트 5% 세 가지, 오판 위험은 (α 5%, 검정력 80%)·(α 20%, 검정력 50%) 두 가지. IR ≤ 0 이면 "정의 안 됨" |
| 참고값 (판정에 쓰지 않음) | 전략·BTC 각각의 CAGR·변동성·샤프·MDD, 베타, 알파, 평가비율(잔차 기준), 연 회전율·연 비용, 연도별 수익률 |
| 종료 기준 | 한도(16시간) 안에서 타당한 IR·D 가정을 확보하지 못하면 **"N 산정 불가"**로 종료한다. 하나의 추정치로 N 을 확정하지 않는다 |
