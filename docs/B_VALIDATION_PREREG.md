- 세션 슬리피지 필드는 아직 없다. §7 의 개발이 끝나야 시작할 수 있다.

## 4. T0

- 42세션이 모두 가동된 공통 시점이다. 현재 T0 정의를 그대로 따른다(`SUPERTREND_VALIDATION_PREREG.md`): 워밍업은 T0 이전 캔들로만 하고, 모든 세션은 현금 1,000,000·보유 0 에서 시작한다.
- T0 가 정해지면 종료 상한은 **T0 + 6개월**이다.

## 5. 종료 규칙 — 두 팔 공동

- **종료 = min(`MAIN`·`STRESS` 가 각각 200거래를 채운 공통 시점, T0 + 6개월).**
  - 거래 = 청산까지 끝난 왕복 하나. 팔의 거래 수는 그 팔 21세션의 합이다. 세는 방식은 현재 검증과 같다.
- 6개월 시점에는 **두 팔 모두 ≥ 100거래**여야 판정한다. 하나라도 부족하면 **판정 불가**다.
- 연장하지 않는다. 더 이른 종료 시점은 추정하지 않는다.

### 5-1. 검증 도중 거래지원 종료 — 사전 규칙

현재 검증은 이 규칙을 BLAST 때 **사후에** 더했다(`SUPERTREND_VALIDATION_PREREG.md` "사후 보완 규칙", 2026-10-27). B 는 **시작 전에** 고정한다.

1. 검증 도중 21코인 중 하나의 거래지원이 종료되면, 그 코인의 **두 팔 세션(`MAIN`·`STRESS`)을 함께** 거래 종료(정지)한다.
2. 정지 **전에** 그 세션들의 미결 주문과 거래지원 종료 전후 주문·포지션·잔고를 대조한다. 현재 무보유라는 것만으로 종료 당시에도 현금이었다고 확정하지 않는다.
3. 대조 뒤 정지하고 **실제 정지 시각**을 기록한다. 거래지원 종료 시각으로 소급하지 않는다.
4. **기존 장부(주문·포지션·거래·손익)를 보존한다.**
5. **코인을 다른 코인으로 바꾸지 않고, 분모(21코인·42세션)를 줄이지 않는다.** T0·종료 규칙·판정 기준도 그대로다.
6. 이후 기간은 **확인된 현금만** 그 금액으로 자산곡선을 잇는다.
7. 🔴 보유가 남아 있거나 평가 자료가 미확정이면, **가상 청산이나 0 수익으로 채우지 않는다.** 그 코인의 결과는 미확정으로 남는다. 판정 시점까지 확정되지 않으면 새 실험 집계 경로가 계산하지 않고, 결과는 **판정 불가**다.
8. 그 코인의 두 팔이 이미 센 거래는 §5 거래 수에 그대로 들어간다. 종료 뒤에는 새 거래가 생기지 않는다.

## 6. 판정 — 수익 후보 자격

`SUPERTREND_VALIDATION_PREREG.md` §4(나) 표의 **지표·임계값·정의를 그대로** 쓴다. 바뀌는 것은 코인 수(21)뿐이다. 주 비용 열은 `MAIN` 팔로, 스트레스 열은 `STRESS` 팔로 계산한다.

| 지표 | 주 비용(`MAIN`) | 스트레스(`STRESS`) |
|---|---|---|
| 코인 동일가중 평균 순수익 | **> 0** | **> 0** |
| 중앙값 순수익 | **> 0** | 보고만 |
| 양수 코인 수 | **≥ 12 / 21**(기존 숫자 12 유지. 결과를 보고 조정하지 않는다) | 보고만 |
| 거래당 순수익률(§4(나) 분모 정의) | **≥ 0.10%** | **> 0** |

| 결과 | 조건 |
|---|---|
| **충족** | 주 비용 네 항목과 스트레스 두 항목이 모두 충족 |
| **미충족** | 하나라도 미달 |
| **판정 불가** | §5 에서 6개월에 한 팔이라도 100거래 미만 |

- 비교 판정(현재 검증의 (가))은 없다. 단일 후보의 자격만 본다.
- 순수익·거래당 순수익률의 계산 정의(장부 재구성, 일별 평가, 왕복 매칭)는 현재 집계기와 같다. 새 실험 집계 경로가 그 계산 함수를 재사용한다(§7 ⓔ).
