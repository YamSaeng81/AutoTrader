# 실전 진입 기준 — 별도 사전 등록: BTC·ETH 주간 시계열 모멘텀 (초안 v1, 고정 전)

> **상태**: 초안(2026-10-29, 리뷰 35차 판정 반영). **아직 고정되지 않았다.** 리뷰가 [`RESEARCH_PROPOSAL_TS_MOMENTUM.md`](RESEARCH_PROPOSAL_TS_MOMENTUM.md) "리뷰 판단이 필요한 것" 1·2번을 정한 뒤 고정한다.
> 이 문서는 후보 하나(TSMOM 28일, BTC·ETH, 주간 판단)에만 적용한다. 기존 [`LIVE_ENTRY_PREREG.md`](LIVE_ENTRY_PREREG.md)는 **바꾸지 않는다** — 기존 66세션의 기준, 22코인 순서 목록, 60일 상한, ≥ 8/22 는 그대로다.
> 운영은 `98aaac4`, STAGE_1 비활성. 이 문서가 고정돼도 실전 진입 승인이 아니다.

## 3. 1단계 종료 조건

| 항목 | 이 후보 | 기존 기준과의 관계 |
|---|---|---|
| 총 왕복 | **≥ 30** | 같음 |
| 판정 가능 코인 | **2 / 2** (두 코인 모두 왕복 ≥ 3). 한 코인이라도 ⚪ 면 판정 불가 | 기존 ≥ 8 / 22. 🔴 대상 전체를 확인하는 조건이지만 **판정 범위가 8코인 → 2코인으로 줄었다.** "강화"로 부르지 않는다 |
| 기간 상한 | **최대 52주.** 미달이면 판정 불가 → 2단계 없음, 이 후보 종료 | 🔴 기존 60일보다 **길다.** 주 1회 판단으로는 60일 안에 30왕복이 구조적으로 불가능해서 둔 후보 전용 절차다(리뷰 35차 (나)). 편도 30건으로 세지 않는다 |
| 연장 | 없음 | — |

## 4. 비용 재판정과 증액

| 항목 | 정의 |
|---|---|
| 측정 | 기존 §4 정의 그대로(부호 구분, D2 금액 기준, D3 측정 불가 분리, D5 페이퍼 제외, D6 코인별 > 0.60% 도 평균에 남김). 왕복별 → 코인별 단순평균 → 두 코인 동일가중 = ③ |
| 재판정 계산 | 고정 계산기를 **개발 자료와 전향 52주 자료 각각에** 재시뮬레이션. 편도 슬리피지 = max((③ − 0.10) / 2, 0.10), 수수료 편도 0.05%. 결과에서 비용을 빼는 사후 차감은 쓰지 않는다 |
| 증액 조건(모두) | ① §3 종료 조건 충족 ② ③ ≤ 0.40%, 코인별 ≤ 0.60% ③ 재시뮬레이션이 두 자료 모두에서 세 조건(누적 순수익 > 0, 초과 수익 > 0, 낙폭 < 그냥 보유 낙폭) 충족 ④ 1단계 중 계좌 비상 정지 없음 |
| 미충족 | ③ > 0.40% 면 운용 중단. ③ 미충족이면 2단계 없이 종료. 스트레스 팔 통과로 대신하지 않는다 |
| 증액 뒤 | 새 크기에서 다시 ⚪, 왕복 ≥ 3 으로 재판정(기존 §4 단계별 재측정) |
