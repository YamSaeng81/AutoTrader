## 2. 1단계 운용 조건

LIVE 의 실시간 판정과 계산기(완료 H1 모형)의 차이는 제안서 §4-2 ② 대로 따로 기록한다. 🔴 리뷰 39차: 공식 점검 공백은 LIVE V93 과 같은 두 조건(봉 구간 전체가 끝난 전 마켓 점검 구간 안 + 거래소 재조회에서도 없음)으로 결측에서 뺀다. 개발 구간은 고정 입력 파일(`scripts/tsmom/maintenance_windows_tsmom.csv`)을, 전향은 운영 V93 표를 쓴다. 최신 완료 봉 조건에는 예외가 없다 | PAPER 의 판정 불가 처리를 바꾸더라도 **이 후보에만** 적용한다. 기존 66세션의 동작은 바꾸지 않는다 |

## 4. 비용 재판정과 증액

| 항목 | 정의 |
|---|---|
| 측정 | 기존 §4 정의 그대로(부호 구분, D2 금액 기준, D3 측정 불가 분리, D5 페이퍼 제외, D6 코인별 > 0.60% 도 평균에 남김). 왕복별 → 코인별 단순평균 → 두 코인 동일가중 = ③ |
| 재판정 계산 | 고정 계산기를 **개발 자료와 전향 52주 자료 각각에** 재시뮬레이션. 편도 슬리피지 = max((③ − 0.10) / 2, 0.10), 수수료 편도 0.05%. **전략과 비교 기준 모두에 같은 비용.** 결과에서 비용을 빼는 사후 차감은 쓰지 않는다 |
| 표현 | 🔴 평균 비용을 고정해 다시 계산하는 **모형상 재판정**이다. 실체결 경로의 완전한 재현이라고 쓰지 않는다(리뷰 36차) |
| 증액 조건(모두) | ① §3 종료 조건 충족 ② ③ ≤ 0.40%, 코인별 ≤ 0.60% ③ 재시뮬레이션이 두 자료 모두에서 세 조건(누적 순수익 > 0, 초과 수익 > 0, 낙폭 < 그냥 보유 낙폭) 충족 ④ 1단계 중 계좌 비상 정지 없음 |
| 미충족 | ③ > 0.40% 면 운용 중단. ③ 미충족이면 2단계 없이 종료. 스트레스 팔 통과로 대신하지 않는다 |
| 증액 뒤 | 새 크기에서 다시 ⚪, 왕복 ≥ 3 으로 재판정(기존 §4 단계별 재측정) |
