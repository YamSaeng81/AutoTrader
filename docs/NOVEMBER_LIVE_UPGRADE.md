### N01. 거래소 DOWN → UP이 제한시험을 다시 여는지

**코드로 확인한 접점**: 운영 `cad3939`의 `LiveTradingService.onExchangeDown`은 RUNNING 세션을 복구 대상에 넣는다. `onExchangeRecovered` → `restartAfterExchangeRecovery` → `startLocked`는 비상정지 세션을 RUNNING으로 만들고 `started_at`을 현재로 다시 쓴다. 기존 `ExchangeRecoveryRestartTest`는 일반 세션의 자동 복구를 정상 동작으로 검증한다. **개발 지시**:

  - 자리표시자를 실제 SHA 로 바꾸면 바깥 F2-1·F5-3 블록 해시는 달라진다. 위 원문 해시가 실행 사본에도 그대로 나온다고 쓰지 않는다. 내부 추출 대상인 OPS §3-1 과 F3 해시는 각각 위 값과 같아야 한다.
  - 최종 인계의 SHA 는 전체 40자리, sha256 은 전체 64자리로 기록한다. 종료 뒤 cron 전환은 같은 `S` 의 OPS §3-1 에서 `FROM=RUNNING; TO=<최종 상태>` 변수 행만 바꾼 실행 사본과 그 해시를 따로 남긴다.
