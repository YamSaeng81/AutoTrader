## 6. 문구 정정

- "양수 묶음은 모두 수십 건 이하"는 틀렸다. DYN_PAPER COMPOSITE_PULLBACK_MTF M15는 95건·4세션, +1,654원이다. 묶음 중복, 의존성, 버전 혼합이 남아 있어 충분한 독립 표본이라고도 보지 않는다.
- 다른 양수 묶음: PAPER MEANREV_BB H1 27건, MTF_BTC_STRICT H1 5건·M15 38건. 나머지 LIVE·DYN 묶음은 7건 이하다.
- "손익 + 기록 수수료"는 수수료 전 손익이다. 슬리피지 전 손익은 아니다.
- 실현손익 누적 낙폭은 평가손을 포함한 계좌 MDD가 아니다.
- 전 세션 자본을 단순히 더한 분모는 동시에 배정된 한 포트폴리오가 아니다.
- LIVE 163·165의 잔액 대조 차이는 원인 미확인으로 유지한다.
- `ruleset_hash`는 전략 코드 버전이 아니다. 과거 혼합 표만으로 b5cd1d0의 각 전략을 합격·폐기하지 않는다.
