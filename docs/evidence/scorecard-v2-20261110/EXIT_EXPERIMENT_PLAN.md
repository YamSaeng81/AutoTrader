## 기준선 — 현재 b5cd1d0의 실행 규칙(운영 지문 기준)

출처는 `ruleset_snapshot`의 키 있는 PAPER 지문 `7e6f71691064`(H1)·`e0c6a13d1660`(M15)이다. 코드 기본값이 아니라 운영이 실제로 쓴 값이다.

| 항목 | 값 |
|---|---|
| 손절 폭 | `clamp(ATR14/가격 × 1.5, 하한 = 세션 stopLossPct(null이면 0), 8%)` |
| 손절가 | 위 손절가와 전략 제안 SL 중 더 넓은 쪽(`min()`) |
| 손실 중 조임 | 없음(`exit.slTightenOnLoss=false`) |
| 익절 | `max(전략 제안, 진입가 × (1 + 손절 폭 × 2.0))`, 상한 8% |
| TP 트레일링 | 고점 × (1 − 0.5%), 올리기만 함 |
| 전략 SELL 관문 | 최소 보유 180분, 최소 수익 +0.3%, 손실 탈출 −0.3% |
| 시간 청산 | 세션값. PAPER 생성 기본은 24시간 |
| 투자 비율 | 세션값, 없으면 0.8 |
| 비용 | 수수료 0.05% × 2, PAPER 슬리피지 0.1% × 2 |

시작 손절가 복원:
- 조임 제거 키가 있는 포지션: 저장된 손절가 = 시작 손절가(README §1).
- 키가 없거나 지문이 없는 포지션: 복원 불가(미확인). 실험 기준선의 근거로 쓰지 않는다.

## 가설 하나

**H1: 고정 코인 PAPER 세션에서 손절 하한 5%(`stopLossPct=5`)를 두면, 하한이 없는 기준선보다 비용 뒤 투자금 대비 순손익이 높다.**

바꾸는 것은 세션 `stopLossPct` 하나다. 다만 익절이 손절 폭에서 파생되므로 익절 목표도 함께 바뀐다. 이 파생은 가설에 포함하고 숨기지 않는다.

이 가설을 고른 근거(진단, 평가 아님):
- 조임 제거 뒤 PAPER에서 손절 하한 5% 갈래는 136건 +0.03%였다.
- ATR 전용 갈래는 111건 −0.34%였다.
- 하지만 5% 갈래에는 `slAtrMultiplier 2.5`·`tpRrMultiplier 1.2`·투자 비율 0.8이 같이 걸려 있고 기간도 다르다. 효과를 분리할 수 없다. 그래서 다른 조건을 모두 같게 둔 전향 비교로 확인한다.
