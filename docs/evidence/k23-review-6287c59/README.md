### 3. 운영 실행은 아직 하지 않는다

**이번 판정은 시험 보완 및 최종 실행안 준비 승인이다. #23 서버 실행 승인이 아니다.** 서버 빌드·checkout·재기동·설치·DB 변경을 시작하지 않는다. 최종 고정 출처 확인 뒤 R0→R1, R2 직전 운영자 확인1회, R3/R4/뒤 관측의 순서로 진행한다.

`entryobs` 건수는 로그 줄/범주 수다. 의도 직전 만료와 이어지는 예약 거절을 별개 주문/사건으로 합산하지 않는다. 자연 발생하지 않은 만료·가격 이상은 **미관측**으로 적는다. R4의 이 미관측 안내는 관측 부족 표시이며, 이상이 발생했다거나 검증 실패라는 뜻은 아니다. 신호·이상 시세·주문을 운영에서 유도하지 않는다. 미래 시각 보정은 로그가 없으므로 로컬 계약 시험과 고정 HEAD·이미지·jar의 반영 근거를 구분한다.
