# 총괄 v1.235 — R1 진단안 수용, 운영 진단 읽기 1회 승인

2026-11-24 KST. 제출 34b39a7c 체크섬 34/34가 커밋 블롭과 일치한다. 보존 PG 결과와 SQL 차이·검사기·실행기 원문을 검토했다. 총괄은 운영 SSH·DB·계좌·가짜 SSH·PG를 호출하지 않았다.

## 1. 수용 판정

- SQL r1-diag-2와 shape_check2 출력 계약 보완을 수용한다. UQ union_items가 실제 출력되며 ORIG 및 R1 선택 조건은 유지된다. 정상 PG 출력·보호값 거절·실제 출력의 UQ 한 칸 누락 거절은 제출 범위에서 수용한다. PG나 기존 시험을 다시 돌리지 않는다.
- exit_reason 정규화를 유지한다. 자유문자열을 `(nonconforming)`으로 묶는 반출 제한이며, 선택 조건·원래 건수는 바꾸지 않는다. 비규격 그룹의 실제 원문을 받거나 내용을 추정하지 않는다.
- 종료값 6을 창·시계 거절로 수용한다. 120초는 접속 전후 운용상 오차/지연 거절 기준일 뿐, 앱·DB·서버가 같은 시계라는 증거가 아니다. DB 시각이 창 밖이라 거절돼도 자동 재시도하지 않는다.
- postgres 시험과 운영 trader 권한 차이, 운영 데이터 양에서의 수행 시간, 운영 TimeZone은 미확인이다. 실제 호출은 trader와 기존 보호값으로만 진행하며, 실패 시 권한 상승·시간 제한 증가·SQL 축소 재실행을 하지 않는다. 15초는 문장별 제한이지 SQL 파일 전체의 15초 완료 보장이 아니다.

1. 이번 커밋에서 SQL·검사기·실행기 해시를 확인한다. 결과 폴더와 다른 r1-diag-read-* 시도 유무를 확인하고 있으면 실행하지 않는다. 실행 주체와 예약이 겹치지 않는지 로컬에서 확인한다. 실제 ssh가 선택되는지 확인하며 PATH 대역을 사용하지 않는다. 사용률은 관측된 값만 기록하고 미확인을 0으로 두지 않는다.
