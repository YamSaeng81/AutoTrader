**조치:** 두 서비스의 태그 조회 결과를 존재·명시적 부재·조회 불명으로 나눈다. 존재하면 기대 대응을 대조하고, 부재가 확인됐을 때만 만든다. 권한·daemon·API·형식 오류는 변경 전 중단한다. `same3`도 대응 불일치와 조회 실패를 구분해 호출자가 실패를 다른 상태로 추정하지 않게 한다.
