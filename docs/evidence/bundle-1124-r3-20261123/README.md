## 1. A3 — 시각·안정성·S 대상 근거 없이는 '충분'을 내지 않는다 (§3-2)

### 1-1. 필수 입력과 보류 조건 — [a3/a3calc2.py](a3/a3calc2.py)

## 2. 월 손실 — 현금 감소를 손실로 세지 않는다 (§3-3)

### 2-1. 철회와 정정

- **철회:** r2 §2-2의 `실현 손익 = available_krw − 배정 시작액`. 매수 원금과 예약금까지 손실로 잡는다.
- **철회:** r2 §2-1의 "세션 −15,000원이 먼저 걸리고". −15,000원은 관측·사람 판단 정지 기준이며 체결 손실을 보장하는 상한이 아니다([v1.219](../review-5ffde2e1/README.md)). 자동/확실한 집행으로 쓰지 않는다.
- **기간 순손익 = 순자산 변화 − 외부 순유입**(v1.218). 순자산 = 현금(`available_krw`) + 미체결 잔여 매수 예약금 + 보유 평가(수량 × 같은 포착의 가격). 각 항목은 한 번씩만 센다. 이 정의는 고정 [성적표 v5](../dec-scorecard-source-v4-20261120/README.md)의 `snapshot()`(가용 KRW + `pending_buys` + 포지션 평가)과 같다. 일부 체결된 예약·CLOSING·가격 없는 보유는 그 시점 평가를 미확정으로 둔다.
- 세션 배정/회수(ALLOCATE/RECOVER)는 세션 경계의 자금 흐름이다. 합산 안의 세션 간 이동은 상쇄하며 거래소 입출금과 섞지 않는다. 부분 체결·환급·미정산은 장부의 확정 여부를 따르고 원금을 임의로 복원하지 않는다.
- **실현손익 부분 합**은 확정 매도 순대금 − 대응 매수 원가·수수료 배분으로 주문 원천에서 계산한다(성적표 v5 `realized_known_part`, W4 R1). 열린 원가/수량·미확정 수수료·시세를 0으로 채우지 않는다.
- 가용 잔액 식은 **주문·보유·예약이 없고 배정/회수·정산이 모두 확정된 경우**의 보조 대조로만 쓴다.
- **누적**(단계 시작 대비)과 **최근 24시간**(24시간 전 포착 대비)의 기준 시점을 따로 적는다. 24시간 전 포착이 없으면 단계 시작 자산으로 대신하지 않고 미확정으로 둔다.
