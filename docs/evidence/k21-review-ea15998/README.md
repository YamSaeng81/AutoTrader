### 1. 상위 결과를 잘못 짝지어 정상으로 인정함

- `cross-thread`: `[scheduler-7]`의 CryptoPanic HTTP403 뒤에 다른 `[http-nio-8080-exec-2]`의 같은 sourceId/HTTP403 결과를 넣었다. 해당 HTTP의 결과로 확정할 수 없어 ⚪/종료3이어야 하지만 **종료0·짝1**이다.
- `two-warns-one-result`: 같은 스레드의 HTTP403 두 줄에 상위 결과는 한 줄만 넣었다. 하나는 미확인으로 남아야 하지만 **종료0·짝2**다. 하나의 결과를 두 번 사용했다.
- `same-thread-control`: 같은 스레드의 정상 HTTP403 한 줄/상위 결과 한 줄은 종료0으로 유지된다.

**최소 보완 지시**: 로그 머리의 스레드를 읽어 같은 스레드·sourceId·HTTP 상태의 결과만 연결하고, 상위 결과 한 줄은 한 HTTP 경고에만 쓴다. 사이에 같은 스레드의 다음 HTTP/수집 시도 경계가 오면 이전 요청의 증거로 넘겨 쓰지 않는다. 경계/짝이 불명확하면 ⚪/종료3으로 남긴다.
