# 총괄 v1.237 — 진단 수용, 과거 무원천 행의 예외 확대는 보류

2026-11-24 KST. 제출 33a62bbb의 체크섬 19/19을 커밋 블롭으로 확인했다. READ_OK와 DYNAMIC 9의 분해 결과를 수용한다. 총괄은 로컬 Git·보존 파일만 읽었고 운영 호출·PG·제품 시험·빌드는 하지 않았다.

## 1. 판정

- 같은 진단 스냅숏에서 DYNAMIC R1 9 = REAL CLOSED 포지션 9개, 연결 주문 없음, exit_reason NULL이다. A 분기는 0이고 PAPER·세션 없음 혼입도 없다. 무거래 확정의 증거는 아직 없다.
- V81/V87 이전 매수 가설은 이 9건의 설명으로 지지되지 않는다. 다만 열린 시각만으로 모든 과거 원천 손실 가능성을 배제하지 않는다.
- AGE D00_06은 남은 기간의 일 단위를 버린 값이 0~6이라는 뜻이다. 남은 시간이 정확히 6일 이하라는 뜻은 아니며 **7일 미만**이다. 새 대상이 없고 시계·조회 계약이 유지되면 DB 시각 기준 **12-01 04:49:14.512Z 이전**에 이번 9건이 30일 창을 벗어난다. 이는 만료 재관측이나 12월 1일 아침 시작 보장이 아니다.
- 주문 없음만으로 무거래라고 인정하는 예외 확대, 과거 exit_reason 채우기, 삭제, 손실 관문 우회는 승인하지 않는다. 자연 만료는 대안으로 남기되 무조건 기다리기로 결정하지도 않는다. 코드 근거와 최소 추가 증거안을 먼저 완성한다.
