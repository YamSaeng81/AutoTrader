## 보완할 해석·집계

### 1. 0.40%는 저장된 손절가의 거리다 — 옛 결함과 현재 규칙을 나눈다

`score.py`는 현재 남은 `position.stop_loss_price`와 진입가의 차이를 계산한다. PAPER 중앙 0.3996004% 자체는 재현됐다. 그러나 최초 손절 설정을 복원한 값은 아니다.

코드 이력 `ddc6de2c85a83a5df3ee382018805ffff5bd345a`(09-08)는 PAPER의 손실 중 SL 조임을 제거했다. 그 전에는 진입 직후 하락에 `저점 × (1−margin)`으로 SL을 올렸다. 현재 b5cd1d0의 `ExitRuleChecker.updateTrailingStops`는 **SL을 그대로 반환하고 TP만 바꾼다**. 호출부에 `setStopLossPrice`가 있다는 사실만으로 현재도 SL을 조인다고 해석하면 틀린다.

따라서 8~9월 표본의 0.40%를 현재 정책의 하자로 곧바로 일반화하지 않는다. 코드 커밋 날짜를 실제 배포 경계로 대신 쓰지도 않는다. 최초 매수 로그·주문/지표·확인 가능한 배포 이력으로 초기 SL과 이후 변경, 규칙판을 구분한다. 복원 불가하면 그 항목은 미확인이다. 최초 TP도 같은 주의가 필요하다. 이 확인 전에 새 손절 폭을 최적화하지 않는다. 과거 결함 제거가 현재 수익성을 보장하는 것도 아니다.

### 2. 660은 독립 거래 수가 아니다

제출 함수의 키는 `(coin, 진입 분, 청산 분)`이고 같은 묶음의 첫 행만 성과 계산에 쓴다. PAPER 660 / DYN_PAPER 424는 **분 단위 시각 묶음 수**다.

PAPER의 복수 행 묶음 218개 중 163개는 거래 수익률이 서로 다르고 5개는 주기도 다르다. DYN_PAPER는 복수 행 묶음 40개 중 32개에서 수익률이 다르다. 이를 완전 중복으로 지우거나 첫 행을 임의로 대표시켜 평균·승률을 독립 표본 추정치로 쓰지 않는다. 시각이 다른 거래도 시장·보유 구간을 공유하므로 독립이 보장되지 않는다. 원래 모든 행을 보존하고 시각 군집·완전 동일 거래·전략/규칙판·자본 가중을 구별한다. 불확실성 분석은 시간 의존성과 같은 시장 노출을 보존하도록 설계한다.

### 3. 관문 영향이 작다는 결론은 보류한다

손익 표는 현재 추출한 세션에 연결된 포지션만 쓰지만 신호 표는 세션 연결을 확인하지 않고 전략 이름으로 합친다. PAPER BUY 5,536건 중 연결된 것은 1,433건, 연결되지 않은 것은 4,103건이다. MTF_CONFIRMED의 578건은 연결 114 + 미연결 464다. ICHIMOKU_V2의 393건은 연결 237 + 미연결 156이다.

손익과 같은 세션·전략/주기·구간으로 신호를 연결하고, 미연결 신호는 별도 과거 자료로 남긴다. 거래별 신호/주문 연결이 없으면 유입률을 근사치로 표시한다. 관문 차단 빈도만으로 손익에 미친 효과를 알 수 없다. 후보 목록·선택/경쟁 정책의 이력도 이번 자료로 검증되지 않았다. 생략된 SELL이 이후 손절로 바뀌었다는 인과도 현재 표만으로 확정하지 않는다.

### 4. 33%와 약 42%는 같은 모집단의 비교가 아니다

33.4%는 전체 DYN_PAPER 473건의 승률(158건 양수)이다. 약 42%는 STOP_LOSS 평균 손실과 TAKE_PROFIT 평균 이익 두 값만으로 만든 가상 손익분기 승률이다. 두 청산 사유는 220건이고 양수는 84건이다. 나머지 TIME_STOP 116, STRATEGY_SIGNAL 110, FORCED_STOP 20, 사유 공란 7건을 제외한 계산을 전체에 적용하지 않는다.

실제 전체 기대손익은 모든 청산 사유의 빈도와 손익, 투자 규모를 포함해 계산한다. 42%는 두 결과만 있다고 가정한 참고 예시로만 표시한다. 이 표만으로 진입 신호의 적중률 부족을 확정하지 않는다.

### 5. 보유 비교는 봉의 마감 시각·비용을 맞춘 뒤 다시 본다

`extract3.sql`은 H1 **시작 시각** `c.time <= ended_at`인 봉의 종가를 끝 가격으로 쓴다. 그 종가가 세션 종료 시점에 이미 알려졌다는 보장이 없다. 저장된 H1 종가의 이용 가능 시각은 시작 + 1시간이다. 시작 가격도 시작 이후 첫 봉의 종가라 비교 구간이 세션과 어긋난다. 현재 17/150 등을 정확한 동시점·동비용 초과 성과로 확정하지 않는다.

시작·끝에서 마감된 가격만 사용하고 실제 비교 경계를 밝힌다. 같은 배정 자본·양쪽 비용을 맞추며 남는 시점 차이와 전략의 현금 비중을 함께 표시한다. 보유는 여전히 참고 지표다. 보유보다 못했다는 것만으로 절대수익 후보를 탈락시키지 않으며, 보유를 이겼다는 것만으로 승격시키지도 않는다.

### 6. 범위와 문구

- “양수 묶음은 모두 수십 건 이하”는 정정한다. DYN_PAPER PULLBACK_MTF M15는 95건이다. 중복·의존성과 버전 혼합을 해소하지 못했으므로 충분한 독립 표본이라고도 단정하지 않는다.
- 코드 SHA·설정·규칙판별 분리는 여전히 필요하다. `ruleset_hash`는 전체 전략 버전이 아니고 현재 메타데이터가 모든 과거 거래 당시 설정과 같다는 보장도 없다. 과거 혼합 표만으로 현재 b5cd1d0의 각 전략을 합격/영구 폐기하지 않는다.
- 순손익은 저장된 포지션의 실현손익이다. `손익 + 기록 수수료`는 **수수료를 더한 값**이며 슬리피지 전 손익이 아니다. 모의 고정 슬리피지와 실전 체결 비용은 다르다. LIVE 163/165의 잔액 대조 차이는 원인 미확인으로 유지한다.
- 실현손익 누적 낙폭은 보유 중 평가손을 포함한 계좌 MDD가 아니다. 전 세션 자본을 단순 합산한 분모도 동시에 배정된 한 포트폴리오가 아니다.

## 세 판단과 추가 확인 없이 이어 갈 작업

1. **66세션 중간 성과 비열람 유지.** 앞선 작업안의 “중간 진단” 표현은 기존 계약에 우선하지 않는다. 별도 추출/집계 승인이 없는 상태에서 성과를 열지 않는다. 기존 위험·운영 감시는 계속한다. 이미 노출된 전체 CLOSED 건수는 일탈 기록으로만 남기고 기준·T0·분모·종료를 바꾸지 않는다. 자동 무효·재시작·표본 제외도 하지 않는다.
2. **SMA20 BTC 전향 모의 추진.** 지금 시작해야 앞으로의 자료가 쌓인다. 목표는 SID 203의 전략·H1·초기 20,200원·투자율 0.995·매수 상한 20,000원·손절 5·maxHoldHours 0·관문/승인 만료/청산/비용을 가능한 범위에서 고정한 독립 모의다. 다만 현행 b5cd1d0 PAPER 요청은 최소 원금 100,000원이고 `maxInvestment`가 없다. 10만원에 투자율만 낮춘 뒤 “같은 2만원 조건”이라고 부르지 않는다. **운영 b5cd1d0 기점의 격리 사본에서 차이표·최소 지원 후보(필요할 때만)·국소 시험·전향 설정/시작·종료·버전 기록안을 곧바로 준비한다.** 메타데이터/연구 기록으로 SHA를 남길 수 있으면 대규모 스키마 개편을 선행하지 않는다. 기존 PAPER 기본값·66계약·REAL 경로는 바꾸지 않는 방향을 우선한다. 운영 세션 생성/시작·배포는 이 구체안의 검토 뒤이며 아직 실행 승인이 아니다. 미배포 V95나 기존 main 변경을 함께 넣지 않는다. 로컬에서 실제 운영 경로를 쓰는 후보까지 검증한 뒤 다음 결과로 제출한다. 다른 시점에 시작하는 실전/모의는 동일 기간의 쌍 비교 구간을 별도로 고정한다. 12-01 전 소수 거래로 수익성 검증을 완료했다고 보지 않는다.
3. **청산 구조 연구 진행.** 먼저 위 1~6을 기존 원문으로 보완한 성적표 v2를 낸다. 추가 DB 조회가 꼭 필요하면 기존 승인 범위의 읽기 전용·522~587 조건 제외·필요한 매수/청산 근거만으로 제한하고 조회·보존 사실을 적는다. 그다음 현재 규칙의 기준선과 바꿀 한 가설을 명시한 로컬 실험 설계를 작성한다. 이미 본 8~9월과 이번 집계로 노출된 모든 후속 기간은 개발/진단 자료다. 10~11월을 날짜만 보고 미열람 평가 자료로 지정하지 않는다. 평가 기간·지표·자본/비용·시도 수·미확인/중단 조건을 결과 전에 고정한다. 초기 SL 복원 가능 여부를 먼저 해결하고, 부족한 장중 자료를 OHLC 경로 가정으로 채워 통과시키지 않는다. 기존 자료의 진단과 최소 재현은 추가 착수 승인 없이 진행하되 새 최적값 탐색·최종 평가·운영 튜닝은 설계 검토 뒤다. 다음 제출은 **성적표 v2 + 현재판 차이/SL 이력 + SMA20 전향 최소안 + 청산 실험 계획**으로 묶는다. 단위 시험 수 늘리기나 이미 통과한 전체 회귀의 반복으로 대신하지 않는다.
