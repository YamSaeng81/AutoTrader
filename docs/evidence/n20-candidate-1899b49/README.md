## 바꾼 것 (HeldMarkRefresher 한 파일)

1. **항목 격리**(N19 와 같은 방식)
   - 시세 루프 안에서 항목마다 검사한다.
     - market 이 문자열이 아니면 그 항목만 건너뛴다.
     - 숫자 변환은 그 변환에만 좁게 `NumberFormatException` 을 잡는다.
     - 0·음수는 `MarkPriceBook.isPrice` 로 걸러 `observe`·`byTrade` 에 들어가지 않는다.
   - 누락·null·체결 시각 이상의 조용한 건너뜀은 그대로다.
   - 새 마켓 정규식·허용 목록은 만들지 않았다.
2. **고정 WARN**
   - 사유는 셋이다: `[시세 보강] 시세 항목 건너뜀 — 가격 형식이 숫자가 아님` / `— 가격이 아님 (부호=0|음수)` / `— 코인 형식이 문자열이 아님`.
   - 인자는 부호뿐이다. 응답의 market·가격·예외 문구는 싣지 않는다.
   - 호가가 충분해 회복돼도 WARN 은 남는다. 실패 알림은 새로 더하지 않았다.
3. **시세 조회 실패와 내부 처리 실패를 나눴다**
   - `getTicker` 예외는 오류문 `시세 조회 실패; ` 로 남는다. 종전과 같이 WARN 줄은 없고, 관측을 못 얻으면 ERROR·경보 본문에 들어간다.
   - 루프 안 장부 등 내부 예외는 항목 건너뜀으로 삼키지 않는다.
     - 종전처럼 배치를 멈추고 오류문 `시세 처리 실패; ` 를 남긴다.
     - 고정 WARN `[시세 보강] 시세 처리 실패 (종류=…)` 1줄을 더했다. 호가로 회복돼도 내부 예외가 기록에 남게 하려는 것이다.
4. **예외 문구 제거**
   - 코인별 호가 실패: `<코인> 호가 조회 실패; `. 호가 형식 이상도 종전처럼 그 코인의 호가 실패다.
   - 회차 오류: ERROR `[시세 보강] 회차 오류 (종류=…)`.
   - 경보 전송 실패: WARN `[시세 보강] 경보 전송 실패 (종류=…)`.
   - 로그에는 예외 클래스의 단순 이름만 남긴다. 오류문·실패 표시·경보 본문에는 그것도 넣지 않는다.
5. **호가 INFO 문구**를 `[시세 보강] 호가로 보강한 보유 [...] — 보유량을 매수호가에 채운 평균 가격으로 관측` 으로 바꿨다("체결이 조용한" 삭제).
6. **그대로 둔 것**
   - 주기: 15초, 기동 뒤 5초. REFRESH_AFTER 60초, 120초 유효기간·미래 시각 보정.
   - 호가 규칙: 깊이·평균·보유량 재조회, 얕은 새 호가가 대신하는 규칙.
   - 실패 처리: 관측 없음 ERROR·경보 1회, 사유 변경 WARN, 지속 DEBUG, 회복 WARN, 차단 방향.
   - 그 밖: DB 질의·트랜잭션·설정·재시도·주문 경로, byTrade 의 "이번 체결 + 60초" 조건.
