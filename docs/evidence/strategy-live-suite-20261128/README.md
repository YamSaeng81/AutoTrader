# v1.262 전략별 실운영 시험 — 누적 매수대금·수수료 총5만원

사용자는11-28 전략별 다양한 운영 시험을 승인했고, 추가 질문에 **누적 매수대금·수수료 총5만원**을 선택했다. 원금을 매도 후 재사용해 무제한 회전시키는 승인이 아니다. 이미 완료된 외부 시험의 매수 원가9,954.18210375원을 포함한다. 운영 대리인 총괄이 단일 실행자다.

## 사전 고정한7개

모두 KRW-BTC/H1, 세션별 원금10,000(앱 최소액)·비율0.55·매수 대금 상한5,500·손절5·시간 청산0·maxEntries 정수1이다. 시험 자본은 한 번에1개 세션만 배정하고 정지/정산 뒤 해제된다. SID203은 변경/시작하지 않는다.

1. COMPOSITE_BREAKOUT
2. COMPOSITE_MOMENTUM_ICHIMOKU_V2
3. COMPOSITE_REGIME_ROUTER
4. SUPERTREND
5. RSI
6. BOLLINGER
7. ATR_BREAKOUT

뒤4개는 현재 제품의 EXPERIMENTAL 분류라 요청에 allowExperimentalLive=true를 명시한다. 전략 성과 근거가 있다는 뜻이 아니다. BLOCKED/DEPRECATED·TEST_TIMED는 제외하고 기존 enablement/WF/위험/EMA/레짐/급락·공유 풀 관문을 바꾸지 않는다. 고정 목록은 신호/성과를 본 뒤 바꾸지 않는다.

## 한도와 진행

- 세션마다 매수 대금5,500×실제 수수료 기준으로 확인하고 최대 원가5,600원을 미리 보류한다. 최초 비용+7×5,600=**49,154.18210375원**으로5만원 미만이다. 실제 확정 비용만 누적하고 매도 대금은 예산에 되더하지 않는다.
- 앞 사례의 비용/잔량/원천/종료가 불명확하면 예약액을 풀지 않고 다음 사례를 시작하지 않는다. 재전송·같은 세션 재시작·마감 후 자동 반복은 없다.
- 각 사례 직전 정확한 계좌/수수료·최소 주문·BTC0·활성/보유/정리0·배정20,200·제품/이미지/동일 기동 인스턴스·현재 입력을 새로 확인한다. 기존 사전 관문을 약하게 바꾸지 않는다.
- 실제 API 생성→요청/응답·DB 대조→서버 관측 armed→시작1회→자연 신호를 관측한다. BUY는1회 정산 후 정지/청산한다. HOLD/보유 없는SELL 확정 판단 뒤20초가 지나도 주문이 없으면 무거래 사례로 종료하며,2분 안에 판단 자체가 없으면 그 사실로 종료한다. 주문 대기는 최대10분, 종료 정산 대기는5분이다.
- STOPPED 뒤30초를 더 관측해 뒤늦은 주문/보유가 남으면 다음 사례를 막는다. 기존 gate v4와 거래소 BTC/KRW잠금0·계좌 현금 증감=주문 원천 비용차감 손익을 모두 요구한다. 관측 공백을 연속 관측으로 쓰지 않는다.
- UNKNOWN·원천 NULL/오류·기록 실패·HTTP 불명·미확인 정지/잔량·한도 위반은 전체 배치를 중단하고 확정 완료로 쓰지 않는다. 서버 폴더 CANCEL은 현재 관측기를 정지 경로로 보내고 다음 사례를 막는다.
- API·계좌 원문은 서버 비공개 폴더에만 보존한다. 로컬에는 자기 시험의 상태·판단 사유·원가/수수료/손익·판정·원문 해시만 반출한다. 비밀번호는 쓰지 않고 기존 SSH 키/서버 인증만 쓴다.

## 출처·검증 범위

운영 제품1b719645·이미지66c4eba8·V96 그대로다. preflight는 c24deed8 사본과 동일, safe_api는 v3, gate SQL/판정기는 v4 그대로다. 관측기는 기존 실제 #205에서 사용한 원문을 전략/금액 계약별로 매개변수화하고, 누적 비용·무거래 판단·정지 후 관측·원천/현금 대조를 추가했다.

새 직접 영향 파일 경계31/31 통과. 실제 생성 전에 기존 종료 세션#205를 읽기만 해서 새 snapshot SQL의 문법/열/형태를 확인한다. 이 읽기 성공은 신규 전략·주문 경로 검증 완료가 아니다. 기존 PG·회귀·jar는 반복하지 않고 새 제품 코드·재빌드·DB 스키마/행 편집·cron/전역 위험 설정 변경을 하지 않는다.

HOLD·SELL·관문 차단·무거래는 그 자체의 관측 결과다.7개를 시험했다는 이유로7개가 실제 매수했거나 수익성을 입증했다고 쓰지 않는다. 모든 강제 정지 매도는 자연 전략 매도와 구분한다. DYNAMIC 병행은 아직 별도 조건을 닫아야 하므로 이번에는 LIVE 세션만 순차 시험한다.
