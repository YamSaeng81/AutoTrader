## 3. 남은 것

실제 불변 근거의 원천(값별로 공백 전체의 변경을 배제하는 읽기)과 경계 가격 원천은 아직 없다. 따라서 실제 운영 값은 T 시각 포착이 아니면 미확정이 된다. 이를 위해 거래를 멈추거나 제품 이력 테이블을 만들지 않는다. 체크섬은 [SHA256SUMS](SHA256SUMS)에 있다.
