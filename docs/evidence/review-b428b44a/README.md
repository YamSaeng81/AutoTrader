1. **22:00 전송 성공은 해당 보고 원문에도 있다.** `20261119-2200.txt` 마지막 줄에 `2026-11-19 22:00:03 KST 보고 전송 성공`이 남아 있다. 설치 해시와 일치하는c669ccdc 원문은 HTTP200·응답 ok:true일 때 이 줄을 보고에 덧붙인다. last_send가 덮였어도 해당 회차의 스크립트 성공 기록은 확인된다. 휴대폰 수신은 계속 미확인이다. 다음 보고의 성공2건만으로 22:00 전송을 추정할 필요가 없다.
