### R1. 지정 SID와 REAL 소유 확인을 금액보다 앞에 둔다

현재 SQL의 SESS·OBUY·POS·MAXTS는 지정 SID와 무관하게 모든 REAL 세션을 읽는다. MORD는 kind와 SID만 보고 **그 SID가 PAPER인지 확인하지 않아 PAPER 주문 금액도 선택할 수 있다.** `--reg-id`는 형식 검사/기록에만 쓰이고 허용 대상을 묶지 않는다. 아직 실행되지 않은 초안의 문제이며 실제 금액 유출을 관측한 것은 아니다.
