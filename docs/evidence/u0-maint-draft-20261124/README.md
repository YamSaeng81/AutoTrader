# D81 유지보수 배포용 U0 보정안 — 매매 시작 관문과 분리 (총괄 v1.239 §3-2, 초안)

2026-11-24 KST, Claude Code 로컬 작업이다. **U0·U1·U2는 실행하지 않았다.** 운영 호출, PG, 가짜/실제 SSH는 0회다. 원래 U0 블록(`91ea9342`, D81A2 `65a384e5` 추출본), pf3ok, 배포 전 읽기 v3, 제품, 과거 DB는 바꾸지 않았다. 새 사본만 만들었다. **이 초안은 운영 실행 승인이 아니다.** 보정 칸 `MAINT4`·`M4GATE`는 빈칸이다. 빈칸이면 원래 U0와 같은 문구로 멈춘다.

|---|---|
| 0 | 원래대로 통과한다. `r1-gate.txt`에 "R1 해소"를 남긴다 |
| 1 | `MAINT4`·`M4GATE`가 빈칸이면 **원래 107행 문구로 멈춘다**. 채워졌으면 다음 순서로 진행한다. ① 고정 커밋에서 r1-diag-4·shape_check4·maint_gate4를 꺼내 해시를 확인한다. ② r1-diag-4를 1회 읽는다(PGOPTIONS 15s/2s, 같은 U0 시도에서 이미 결과가 있으면 거절). ③ 조회 실패·표준오류이면 멈춘다(원문은 서버 `$M`에만). ④ 형식 검사 rc0이 아니면 멈춘다. ⑤ maint_gate4가 0일 때만 통과하며 "유지보수 배포 준비로만 통과, R1 미해소, 매매 시작 금지"를 출력한다. 1이면 조건 미충족으로, 그 밖이면 형식 이상으로 멈춘다 |

`|| true`로 거절을 지우는 줄은 없다. 생성·시작 명령은 넣지 않았다. U1~U4는 바꾸지 않았다. pf3ok를 쓰는 블록은 U0 하나뿐이다(U1 이후 grep 확인).

## 3. 판정기 — [maint_gate4.py](maint_gate4.py) (해시는 수용 뒤 `M4GATE`에 고정)

종료값은 0 `MAINT_DEPLOY_ONLY` · 1 `MAINT_STOP` · 3 `MAINT_FORMAT`이다. 0은 아래를 모두 충족할 때만 낸다.

- P1 pf3ok 판정 줄: R1 LIVE 0, R3 RUNNING REAL 청산 행 0·판정 불가 0
- P2 r1-diag-4 ORIG DYNAMIC = pf3ok DYNAMIC(다른 트랜잭션이므로 다르면 멈춤), ORIG LIVE 0
- P3 KNOWN = ORIG DYNAMIC, DYNAMIC OTHER 0, LIVE 대상 0, KNOWN ≤ 9
- P4 NEW 네 칸 0
- P5 REAL RUNNING·PAUSED·OTHER 0, 세션 모드 OTHER 0
- P6 RX 열 칸 0
- P7 소유 불명 OW 20칸 0, 상태 불명 0, 옛 고아 ACTIVE 0. 옛 고아 TERMINAL/CLOSED는 개수만 기록하고 정상으로 재분류하지 않는다

통과 문구에는 KNOWN 수, 마지막 만료 경계, 다음 분을 넣는다. "부류 일치, 동일 행 증거 아님"도 함께 쓴다.

**파일 시험(PG·SSH 0) — [runs/gate-file/summary.json](runs/gate-file/summary.json) 10/10 기대대로:**

| 입력 | 결과 |
|---|---|
| 보존 PG 출력 normal · running_real · minute_edge(OTHER 1) · new_ap | 각각 rc1 `MAINT_STOP`(해당 조건 이름 나열) |
| 보존 PG 출력 empty(R1 0) | rc3. pf3ok 0 경로라 판정기를 부를 경우가 아니다 |
| **합성** KNOWN만 있는 파일(minute_edge 출력에서 OTHER 1건을 손으로 지움) | shape_check4 rc0 → 판정기 rc0 `MAINT_DEPLOY_ONLY` |
| 합성 파일 + pf3ok 수 불일치 / R3 ≠ 0 / 판정 줄 형식 오류 | rc1 / rc1 / rc3 |

**통과 경로는 합성 파일로만 확인했다.** 실제 PG에서 KNOWN-only 사례는 아직 없다. 수용하면 다음 격리 PG 묶음에 넣을 직접 영향 범위는 이렇다: KNOWN-only 정상 → U0-maint 1) 경로 rc0 · r1-diag-4 조회 실패 · 형식 이상 · OTHER 1건 · 소유 불명 1건. 실제 U0 블록 실행(가짜 SSH 포함)은 범위 밖이다.
