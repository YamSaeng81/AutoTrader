# 소액 실주문 시험 원문 초안 — B 포함판 안 B (총괄 v1.243 §3-1, 제출 초안)

2026-11-25 KST. **실행하지 않았다.** 문법 확인(`bash -n`)만 했고, 실행기 전체와 실제·가짜 SSH는 실행하지 않았다. 인증값은 파일에 없다. 서버 `.env`에서 호출하는 그 자리에서만 읽는다. 금액 조건은 사용자 승인 그대로다: 누적 매수대금 + 매수 수수료 ≤ 10,000원, 총예산 100,000원 안. 안 D(d81만 배포 + 사람 정지)는 v1.243 §2에 따라 제외했다.

| 파일 | 내용 |
|---|---|
| [vars.template](vars.template) | 승인값 칸이다. 빈칸이 하나라도 있으면 거절한다 |
| [launch.sh](launch.sh) | 로컬 실행기다. **ssh·POST 전에** 다음을 거절한다(종료 3): 빈 승인 날짜·창·SHA·이미지·풀·배정합·결과 이름, 생성 뒤 단계의 빈 SID, 날짜·창 밖, 결과 폴더 중복, P0·verify 미통과, POST 표지 중복, ssh 경로가 `/usr/bin/ssh`·Windows OpenSSH가 아님(가짜 ssh 방지) |
| [smoke.sh](smoke.sh) | 서버 단계다. 같은 검사를 원격에서 한 번 더 한다 |

## 단계와 판정

| 단계 | 호출 | 통과 조건 → 실패 시 |
|---|---|---|
| p0 | 읽기만 | 설치 SHA·추적 변경 없음, backend 이미지, 공유 풀 4값, 활성 실자금 배정 합 = `ALLOC_BEFORE`, 실자금 활성 주문 0, 정리 대기 0, 거래소 UP, **A3: 주문 가능 KRW ≥ 기존 배정 + 10,000 이고 묶인 KRW 0**, 서버·DB 시계 기록 → 하나라도 다르면 생성하지 않는다 |
| create | POST 1회 | 본문: DAILY_SMA20 · KRW-BTC · H1 · 10000 · 0.995 · 9950 · 5.0 · 0 · `{"maxEntries":1}`. 성공·CREATED가 아니면 재전송하지 않고 보고한다 |
| verify | 읽기 | 응답에서 id = SID, CREATED, REAL, `maxEntries`가 int 1. DB 행이 `CREATED\|REAL\|number\|1\|t\|t\|t\|t`이어야 한다 → 다르면 start하지 않는다 |
| start | POST 1회 | 응답과 DB의 RUNNING을 기록한다 |
| watch | 읽기만 | 그 세션의 주문·포지션·가용액, `ENTRY_LIMIT_REACHED` 로그. **신호를 만들지 않는다** |
| stop | POST 1회 | 정지 직전 보유 건수를 기록한다 |
| gate | 읽기 | [게이트 v3](../one-entry-gate-v3-20261125/README.md). PASS만 종료로 본다. HOLD·FAIL이면 보고한다 |

**대기 종료와 강제 정지는 구분한다.** 창이 끝날 때까지 매수가 없으면 stop은 청산할 것이 없다. 이 경우 **미실행**으로 기록하고 끝낸다. 보유 중에 stop하면 `FORCED_STOP` 시장가 매도가 함께 나간다. 이 매도는 자연 매도(신호·손절·익절)와 구분해 기록하고, 성과 집계에서 빠진다. 정지 직전 보유 건수(`held-before-stop.txt`)로 둘을 가른다.

**A3 미확정(이 원문으로 닫지 않음):** 계정의 실제 수수료율(코드는 0.0005 가정), 거래소 최소 주문액(코드는 5,000 가정), 장부 밖 잔량. 조회가 성공했다는 것만으로 충분하다고 보지 않는다. 위 부등식만 판정에 쓴다.

**구판 복구가 필요할 때:** 게이트 PASS 뒤에만 되돌린다. 구판에서 이 세션을 start하지 않는다. 구판은 DAILY_SMA20 세션의 정지 뒤 시작을 거절하지만, DB 직접 수정은 막지 못한다. 거래소 잔량은 A3·장부로 확인한다. 정지 경합은 해결되지 않았다.

**남은 결정(총괄):** 실행 날짜·창·결과 이름, 설치 SHA·이미지(B 포함판 수용 뒤), 풀 4값·배정합, 대기 창 길이, watch 횟수. 실주문은 승인 전이다.

체크섬: [SHA256SUMS](SHA256SUMS)(자신 제외).
