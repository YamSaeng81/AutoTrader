## 2. 동적 전략·주기 선정 — 결과를 보기 전에 정한 규칙

12월 자료·과거 최고 수익률로 고르지 않는다. 거버넌스 표(`StrategyLiveStatusRegistry`)의 설명 문구는 특정 코인의 과거 백테스트 수익률이라 **순위 근거로 쓰지 않는다**.

| 단계 | 규칙 | 남는 것 |
|---|---|---|
| ① REAL 생성 가능 | 상태 ENABLED(EXPERIMENTAL·BLOCKED 제외, REAL은 BLOCKED 생성 거절) | BREAKOUT·MOMENTUM·MOMENTUM_ICHIMOKU·MOMENTUM_ICHIMOKU_V2·REGIME_ROUTER·MTF_BTC·MTF_MOMENTUM (모두 COMPOSITE_) |
| ② 다수 코인용 설계 | 특정 코인 특화로 정의된 것 제외: MTF_BTC(BTC/ETH 특화), MTF_MOMENTUM(DOGE/ETH 특화), REGIME_ROUTER(SOL 운영 전략) | BREAKOUT·MOMENTUM·MOMENTUM_ICHIMOKU·MOMENTUM_ICHIMOKU_V2 |
| ③ 주기 | H1 — 한 달 안 표본 수와 60초 틱·봉 신선도 관문에 맞는 주기. 일봉은 한 달 표본이 너무 적고, M15는 수수료 비중이 커진다 | 위 4개 × H1 |
| ④ 운영 경로 시험 연결 | DYNAMIC 실제 경로 시험에서 이미 쓰인 조합을 우선(새 경로 위험을 늘리지 않음) | **COMPOSITE_BREAKOUT H1**(금액/BTC 생성·지문 H2/PG), **COMPOSITE_MOMENTUM_ICHIMOKU_V2 H1**(매도 PG·손익 정의 PG의 DYNAMIC 세션) |
| ⑤ 둘 중 하나 | 신호가 추세 이중 필터(ADX·EMA)로 횡보 구간 진입이 적은 쪽을 기본으로 둔다 — 수수료 뒤 손실 위험이 큰 잦은 진입을 줄이는 설계 기준이며 수익률 비교가 아니다 | **초안: COMPOSITE_BREAKOUT H1**, 대안: MOMENTUM_ICHIMOKU_V2 H1 |

참고만: 11-16 화면 읽기의 DYNAMIC 93(COMPOSITE_MTF_CONFIRMED M15, 정지, 청산 7건)은 표본이 작고 ENABLED 목록 밖이라 선정에 쓰지 않는다. 최종 선택은 사용자·총괄 판정 대상이다.

| 칸 | 초안 | 이유 |

| `investRatio` | 0.80(코드 기본) | 30,000×0.8 = 24,000 > 포지션당 20,000이면 상한 없이는 매 진입 거절(P1) → 아래 `maxOrderKrw` 필요 |
| `strategyParams.maxOrderKrw` | 가상 10,000 | 1회 노출을 총원금 결정 전 작게. 5,000 이상·포지션당 상한 이하(후보 계약) |

| `minAtrPct`/`maxSpreadPct` | 0.5 / 0.1 (코드 기본 문구) | 변동성 너무 낮은 코인·스프레드 큰 코인 제외 |

| `stopLossPct` | 5.0(코드 기본) | ATR 손절과 넓은 쪽(경로 표). [손익 정의](../dec-pnl-definition-20261119/README.md) C: REAL 평균가는 매수 수수료 제외라 손절선이 0.05%만큼 늦다 |

DYNAMIC 세션은 한 번에 보유 1개다(보유 중 신규 매수 차단). 가상 예시에서 동시 노출은 SID203 최대 20,000 + 동적 10,000 = 30,000으로 공유 풀 동시 3·총 10만 안이다.

## 4. 진입 순서·위험

- **같은 회차 경합**: 공유 풀 등록 단계에서는 LIVE·DYNAMIC 진입이 회차 승인(`EntryPriorityRounds`)을 거친다. BTC를 제외하므로 같은 코인 경합은 없고, 남는 경합은 공유 풀 총액·동시 수다.
- **손실 한도**: 기존·DYNAMIC REAL·전체 REAL 세 보호식(v1.158). 단 [손익 정의 조사](../dec-pnl-definition-20261119/README.md) 결과 REAL 손실 합은 매수 수수료만큼 과소이고, 비용 뒤 −2.75·가격 +1인 매도는 손실 합·연속 손실에서 빠진다. 시작 전 수정 여부는 총괄 판정 대상이며, 고치지 않고 시작하면 이 차이를 시작 조건 확인표에 적는다.
- **모의 간섭**: DYNAMIC 모의/REAL 쿨다운 종류별 격리(89336440, 통합 ac52715e/aff357e2)가 운영에 없으면 모의 손실로 REAL이 막힐 수 있다. 막힌 기간은 전략 성과로 읽지 않는다.
