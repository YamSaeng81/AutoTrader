## 정정과 관측 범위

CryptoPanic 403은 **고유 2회**다. `07:57:36.454Z scheduler-1`과 `08:27:37.876Z scheduler-4`이며, 두 줄 모두 뒤따르는 같은 스레드의 FAILED/HTTP_403/받은0건·신규0건 결과와 일치한다. L4 누적1회가 L 뒤 누적2회에 포함되므로 3회로 합산하지 않는다. 기존 제출/기록은 보존하고 계획 §66에서 정정한다.

원문 httpobs 출력은 L4 고정1/짝1/미확인0, L 뒤 고정2/짝2/미확인0이다. 제출된 머리 있는 뉴스 발췌도 이에 맞는다. 발췌만으로 전체 로그의 연속 줄/본문 부재를 독립적으로 재검사했다고 쓰지 않는다. DOCTYPE/html 0은 개발의 전체 로그 조회 보고이며, 직접 대조한 것은 보존된 관측 함수 출력·발췌·내용 비교·이전에 수용한 시험이다. 특정 비밀 유출이 있었다거나 403 원인/Connection reset이 해결됐다고 판단하지 않는다.
