## 1. 빈틈

원문 F1(`a1e38e7` 계획 bash 블록 13번, sha256 `b29ad031…`)은 설치 장부만 대조한다.

- 정기 점검 설치판(`INSTALLED_SHA`·`daily_check.sh`·`daily_checks.sql`)은 보지 않는다.

그래서 12-01 08:30 시점에 점검 파일이 바뀌었거나 없어도 F1은 통과하고 `ok-F1`을 만든다(아래 r1의 원문 9/9 통과).

## 2. 제안 — 원문 19행(장부 검사) 바로 뒤에 4줄

[`f1.diff`](f1.diff), 삽입 원문은 [`add.txt`](add.txt)다. 제안 F1 전체는 [`f1-prop.sh`](f1-prop.sh)(sha256 `4c756c43…`)이고, [`mkprop.py`](mkprop.py)가 원문에서 기계적으로 만든다.

- **읽기만 한다.** 세 값을 `$M/install-f1.txt`에 남기고 고정 기대값 `INSX`와 비교한다.
  - `INSTALLED_SHA` 내용(`$(cat)` — 끝 줄바꿈 무시, 기존 `SID_LEDGER_SHA` 대조와 같은 방식)
  - `daily_check.sh` sha256
  - `daily_checks.sql` sha256
- **기대값**: c669ccd / `ff0a5d7d…` / `653b22ba…`. 전체 값은 diff에 있다.
- **누락·읽기 실패**: 그 칸이 `읽기실패`가 되어 불일치로 끝난다. 불일치면 기존 `stop` → 기존 trap 이 당일 `f1-failed-<날짜>`를 남긴다.
  - `ok-F1`·운영자 확인 파일은 F1 머리(원문 12행)에서 이미 지워져 있다. 사본은 `f1-attempts/`에 보존된다.
  - 텔레그램 시험(원문 55행)보다 앞이라 시험 전송도 없다.
- 설치·복구·chmod·수동 점검 실행으로 스스로 고치지 않는다.
- **위치**: 장부 검사 근처이고 공유 풀·DB·거래소·계좌·경보·텔레그램 검사보다 앞이다.

## 3. 국소 대역 시험 — r1 (19:45:11~19:45:59 KST)

[`harness.sh`](harness.sh)·[`runall.sh`](runall.sh)로 돌렸다.
- **대역 범위**: 외부 명령(git·docker·psql·curl·python3 경보·svc·sc)은 모두 함수 대역이다. 실제 start·주문·텔레그램은 부르지 않고 `calls.txt`에 호출만 센다.
- **F 변수**: 계획 원문 F 블록([`F-orig.sh`](F-orig.sh), `ca9b7d23…`)을 첫 줄 `cd`만 빼고 그대로 읽는다(EG·LIVE1·KEEP·BASE·BTCIN 원문).
- **고정물**: 실제 설치판 원본이다. 해시는 운영 기대값과 같다.
  - `git show c669ccd:scripts/ops/daily_check.sh`·`daily_checks.sql`
  - `8bfe8a9:sid_ledger.sql`
- **사례마다 준비**: 옛 `ok-F1`·운영자 확인 파일을 미리 둔다.

## 4. 반영 때의 문서·해시 영향 (반영은 아침 총괄 검토 뒤)

- **바뀌는 블록**: F 15블록 중 **F1 한 블록만** 바뀐다(`b29ad031…` → `4c756c43…`, 지금 출처 기준).
  - 나머지 14블록과 OPS §3-1(`d158e836…`)은 바뀌지 않는다.
  - N06 목록의 "F1은 점검 두 파일 해시를 검사하지 않는다" 빈 곳이 닫힌다.
- **#24와 겹칠 때**: #24 결과 수용으로 F1의 `NEW`/`IMGF1` 핀이 바뀌면 F1 블록 해시가 다시 바뀐다. 두 변경은 서로 덮어쓰지 않게 따로 제시한다.
  - N18: 설치판 4줄.
  - #24: 운영 핀 2곳(F 변수 `NEW`, F1 `IMGF1`·이미지 기록 경로).
  - 함께 반영하면 최종 F1 해시를 그때 다시 잰다.
- **설치판 값**: 원본 S·backend SHA와 별개다. 설치판을 바꾸는 개입(예: 새 점검 판 설치)이 있으면 F1의 `INSX`도 같이 바꿔야 한다. 그렇지 않으면 F1이 시작을 막는다(의도된 동작).
- 최종 S는 정하지 않았다.

## 5. 남는 한계

- **INSTALLED_SHA 끝 줄바꿈**: `$(cat)` 비교라 끝 줄바꿈 개수 차이는 잡지 않는다. 기존 장부 표지 대조와 같은 수준이다. 파일 해시까지 고정하려면 총괄 판단으로 한 줄을 더한다.
- **검사 범위**: 이 대역은 F1 조각과 F2 원문 머리의 연결만 본다.
  - 실제 서버의 파일 권한·docker·DB 응답은 검증하지 않았다.
  - T0/T4가 같은 세 값을 읽어 지금 서버 값이 기대와 같음은 #24 기록에 따로 있다.
