- 검토일: 2026-11-03. 설치판 원문: `8435935e975ceb6c2e16a09ef5b82530574a7da2`.
- `daily_check.sh` 원문 sha256: `a6ddc54994355066b940c276d98d7396e501aad3cce31004475ca35574d4d657`.
- 새 결함은 BTC 값 자체가 아닌 **다른 필수 위험 값의 빈 값·단일 값 키 중복 처리**다. N09의 완료 범위와 실제 첫 자동 보고 수용 판정은 유지한다.

원본 셸 전체에 가짜 SQL 출력을 넣고 `DRY_RUN=1`로 실행했다. 정상 대조군의 SQL 출력은 기존 N09 재현의 정상 자료와 같다. 키/끝 표시가 있는 상태에서 값만 비우거나 같은 위험 키를 두 번 출력했다. 정상 SQL이 실제 운영에서 이런 출력을 만들었다는 근거는 없으며, 운영 장애 발생이나 실제 UNKNOWN/정산 불일치를 주장하지 않는다.
