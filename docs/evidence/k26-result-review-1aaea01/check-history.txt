2026-11-06 총괄 #26 결과 검토 이력

1. 제출 SHA256SUMS의 현재 로컬 107파일과 앞선 승인 11파일 바이트를 확인했다.
   Git batch blob 대조는 out/final-state.txt에서 missing을 발견해 중단했다.
   확인 결과 .gitignore의 out/ 때문에 결과 커밋에 5파일이 빠졌고 나머지 102개는 같다.
   누락은 실제 보존 공백이며 제품 결함이나 체크섬 불일치가 아니다.
   누락 5파일 원문은 현지 체크섬과 같아 preserved-out/에 같은 바이트로 보존했다.
   다음 실제 결과 커밋에서 원본 경로도 명시적 강제 추가하고 107개 블롭으로 재대조한다.

2. 총괄 검사 스크립트가 #25와 같이 서버 해시 목록에서 jar를 빼고 로그5개만
   server-only로 가정해 중단했다. #26 목록은 jar도 들어 있어 jar2+로그5=7개다.
   실제 목록/별도 jar-sha를 읽어 가정을 정정했다. 제출 파일은 바꾸지 않았다.

3. 승인된 blocks-k26/에는 U8개만 있고 F/G는 고정 출처/blocks metadata에 있다.
   검사 스크립트가 F도 그 디렉터리에서 읽으려 해 중단했다.
   F/G는 de5a7e4 원문과 직접 대조하고 U8개만 추가로 승인 보존본과 대조하도록 정정했다.
   열 블록 모두 원문/해시가 같다. 제품/명령/제출 기대값은 바꾸지 않았다.

4. 최종 review.py는 로컬 Git/파일만 읽고 결과 JSON을 남겼다.
   제품 시험, 블록 실행, 서버 재조회, jar 재빌드는 하지 않았다.
