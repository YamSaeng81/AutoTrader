## 입력

- 시세 응답 `[정상 A, 비정상 B, 정상 C]`. 세 코인 모두 최근 체결(5초 전)이다.
- B 의 종류: 정상(대조군), 가짜 표지·줄바꿈이 든 문자열 가격, `abc` 가격, 숫자 market, 가격 0, −1, null, 체결 시각 형식 이상.
- 호가 상황(세 코인 같음): 충분(99×50), 깊이 부족(99×3 < 보유 10), 조회 실패(예외).
- 보충: C 에 기존 WS 체결 관측이 90초·130초 전에 있을 때. B 호가만 형식 이상일 때.

## 결과 (원문 `rows.txt`, 20행)

| B 종류 | 시세 루프 | C 체결 처리 | 호가 충분 | 호가 깊이 부족·실패 |
|---|---|---|---|---|
| 대조군 | 끝까지 | byTrade | 호가 안 부름 | 호가 안 부름·관측 유지 |
| 숫자 아닌 가격(가짜 표지·`abc`) | **B 에서 끊김** | **안 됨**(C 체결가 300 버림) | B·C 호가 평균 99 로 관측, unobserved 0, **ERROR·경보 없음, INFO 1줄** | B·C unobserved → ERROR 1·경보 1·실패 표시 |
| 문자열 아닌 market | **B 에서 끊김** | **안 됨** | 위와 같음 | 위와 같음 |
| 0·−1·null 가격, 체결 시각 형식 이상 | 항목만 건너뜀 | byTrade | B 만 호가로 관측 | B 만 unobserved(0 × 실패 행) |

1. **끊김은 실제로 재현됐다.** 숫자로 바꿀 수 없는 가격이나 문자열이 아닌 market 하나가 시세 루프 전체를 배치 `catch` 로 보낸다. 뒤 정상 코인 C 의 신선한 체결가는 장부에 적히지 않는다.
2. **호가 대체는 호가 상황에 따라 나뉜다.**
   - 호가가 충분하면 C 는 호가 평균으로 관측된다. 풀 판정은 열린다.
     - 이때 `unobserved` 가 비어 `recovered()` 로 끝난다. 그래서 `시세 조회 실패: …` 오류문은 **로그·경보 어디에도 남지 않는다.**
     - 남는 것은 `체결이 조용한 보유 [B, C]` INFO 1줄뿐이다. C 는 5초 전 체결이 있었는데 "체결이 조용한" 으로 적힌다.
   - 깊이가 모자라거나 조회가 실패하면 C 는 관측 가격 없음이다. 공유 풀 신규 진입이 막히고 ERROR 1줄·경보 1회가 나간다.
     - 다른 코인 B 의 형식 이상 때문에 정상 C 까지 막히는 것이다. 다만 방향은 차단(보수 쪽)이다. 매도·주문은 내지 않는다.
3. **기존 신선한 장부**: C 에 90초 전 WS 관측이 있으면 끊김 뒤 호가가 실패해도 C 는 관측 유지다(남은 30초 동안). 출처는 기존 WS 290 그대로이고 새 체결가 300 은 적히지 않는다. 130초 전이면 C 도 관측 없음이다.
4. **호가 경로는 이미 코인별로 격리돼 있다.** B 호가의 `bid_price` 가 형식 이상이어도 그 코인만 `호가 조회 실패` 이고, C 는 호가로 관측된다.
5. **0·음수·null·체결 시각 형식 이상**은 끊지 않는다. 장부 `observe` 가 거르거나 `continue` 한다. 이때 WARN 은 없다(조용히 건너뜀).
6. **오류문·경보·로그의 외부 값**
   - 20행 모두 가짜 표지(`FORGED`)와 줄바꿈이 오류문·경보·로그에 없다.
   - 다만 예외 문구가 그대로 실린다.
     - `abc` 는 `Character a is neither …` 로 **외부 값의 첫 글자 1개**가 나온다. 가짜 표지 문자열은 `Character array is missing "e" …` 로 값이 나오지 않았다.
     - 숫자 market 은 `class java.lang.Integer cannot be cast …` 로 형식 이름만 나온다.
   - 이 오류문은 호가가 실패한 경우 ERROR 줄과 텔레그램 경보 본문에 들어간다.
7. 비용: 끊김이 있으면 C 도 호가 조회 대상이 되어, 회차마다 REST 호가 호출이 코인 수만큼 늘어난다(재현에서 확인. 운영 호출 수는 세지 않았다).

## 결함 여부 판단 재료 (판정은 총괄)

- **기존 방어는 그대로 맞다**: 관측 가격이 없으면 진입 차단, 깊이 부족 호가 불인정, 낡은 체결가 불인정. 이것들을 결함으로 보지 않는다.
- **구체적 공백 후보**:
  - (가) 형식 이상 한 항목이 뒤 정상 코인의 체결 처리를 끊는다. N19 가 고친 `pollRestTickerFallback` 과 같은 모양이다.
  - (나) 호가가 충분해 회복 처리되면 끊김 사실이 기록에 남지 않는다.
  - (다) 예외 문구가 경보 본문에 들어간다.
- **최소 수정 범위를 제안만 한다(만들지 않음)**: ① 루프 안에서 market 이 문자열이 아니면 그 항목만, 가격이 숫자가 아니면 그 항목만 고정 문구로 건너뛴다(N19 와 같은 방식). 주기·한도·120초·호가 규칙·재시도·로그 정책은 그대로 둔다. (나)·(다)를 함께 다룰지는 다음 검토에서 정한다.
- 운영에서 이 끊김이 실제로 일어났는지는 확인하지 않았다. 업비트 응답에서 이런 항목을 본 적도 없다. 자연 발생 미관측이다.
