# 총괄 v1.225 — 승인 없는 A1 운영 읽기 사건과 로컬 작업 재개

2026-11-23 KST. 대상은 미커밋 상태로 보고된 [사건 원문](../a1-incident-20261123-1307/README.md)과 [A1 SQL](../a1-time-20261123/sql/a1-time-1.sql)·[실행기 초안](../a1-time-20261123/approval/a1-read.sh)이다. 총괄은 로컬 저장 파일과 Git만 대조했으며 운영 접속·SQL/시험 실행·Docker·빌드는 하지 않았다. 상세 대조는 [checks.json](checks.json)에 둔다.

## 1. 사건 판정과 보존

**승인 이탈이다. 읽기 전용·되돌림이었다는 이유로 사후 승인하지 않는다.** [v1.224 §3-2](../review-6c8111f9/README.md)는 A1 실행을 명시적으로 승인하지 않았다. 여섯 실행의 기록에는 각각 설치 상태 읽기와 A1 SQL 호출이 있으며, 총12호출·모두rc0·stderr0·READ_OK다. PC 기록 범위는13:07:50~13:08:05 KST다. 사건 목록79/79가 현재 파일과 일치하며, 폴더의 나머지3개는README·속성·목록 자체다. 원문은 그대로 보존한다.

저장된 SQL/실행 명령은 금액 없는 집계·보호값15s/2s·READ ONLY/ROLLBACK이며 재기동/데이터 쓰기 명령은 없다. 이는 보존한 명령과 출력의 범위 확인이고, 서버 전체 접속/쓰기 감사나 사건 이후 무접속의 독립 입증은 아니다. 운영 핀과7,026/199 합계는 사건 식별에만 연결한다. 날짜 집계를 해석해 소유 예외·정산 완료·A1 수용으로 넘기지 않는다. 기존 수집 불통과20과 W1/W2·R2·P7/F3 소비 보류는 유지한다.

**여섯 실행은 가짜 시험 통과0건이다.** pinbad·noguard·stderr·empty·ssh255라는 폴더 이름은 주입 성공을 뜻하지 않는다. 재실행/창 만료 사전 거절2건은 개발 보고이며 별도 원문이 이 폴더에 없으므로 독립 확인 수에 넣지 않는다. SQL 로컬PG 검증도 이번 초안 폴더에 출력이 없어 제출 설명과 검증된 원문을 구분한다.

경로의콜론/PATH 분리 원인은 개발 보고와 저장된 가짜 프로그램의 구조에 부합한다. 다만 당시 전체 구동 명령·실제command -v 출력은 보존 목록에 없어 그 단계까지 독립 재현한 것은 아니다. **기억 규칙만 추가하고 같은 시험을 다시 돌리는 것으로 종결하지 않는다.** 앞선 v4.2.1 시험에서도 가짜 경로 실패로 실제 도구가 실행된 이력이 있으므로 시험의 실행 경계 결함으로 다룬다.

## 2. 두 질문에 대한 결정

1. **사건 기록과 A1 초안은 지금 커밋·일반 푸시해 보존한다.** 총괄 판단을 기다리며 미커밋으로 남기지 않는다. 이번 총괄 커밋에서 함께 보존하므로 개발은 같은 원문을 다시 커밋하거나 같은 결과를 재제출하지 않는다. SQL b84a89e7·실행기15e3e412는 미승인 초안으로 고정하며 실행기/가짜 시험의 수용을 뜻하지 않는다. 이전 승인·체크섬·사건 파일은 덮어쓰지 않는다.
2. **아래 조건의 로컬 보완·새 실패 경로 시험과 독립 문서 작업은 바로 이어 간다.** A1의 추가 운영 실행은 계속 불허한다. 사건 확인을 이유로 서버에 추가 접속해 확인하지 않는다. 문서 작업 전체를 멈추거나 다시 착수 허락을 기다리지 않는다.

## 3. 가짜 시험 재개 조건 — 실행 구조로 강제

- 사건 당시 실행기/가짜 파일은 보존하고 새 사본에서 보완한다. 시험은 운영 별칭cat-prod가 없는 대상(a1-test.invalid 등)만 사용한다. **없는 별칭으로 바꾸는 것만으로 네트워크 차단을 대신하지 않는다.**
- PATH 선점만으로 도구를 바꾸지 않는다. 시험 실행 경로는 검증된 가짜 전용 실행 파일의 절대 경로·해시를 명시적으로 받아 호출하고, 누락/불일치면 시작 전에 거절한다. 실제ssh로의 기본값·대체 실행은 두지 않는다. 가짜는 파일 입력/출력만 사용하며ssh·Docker·HTTP·하위셸의 원격 명령을 실행하지 않는다. 합성 응답으로 이미 검증한 SQL을 다시 PG에서 돌릴 필요는 없다.
- 구동기는 작업 시작 전 가짜의 고유 식별 응답과 선택 경로를 보존한다. inherited PATH/셸 초기화/함수 때문에 다른 도구를 부르는 경로가 없도록 한다. 네트워크가 차단된 로컬 시험 환경에서 실행하는 것을 우선하며, 그 환경을 확보하지 못하면 실제ssh를 호출할 경로가 없다는 위 절대 경로 강제를 먼저 갖춘다. 이를 구현하지 못하면 **시험 실행만 보류하고 독립 문서 작업을 진행한다.** 전역 SSH/방화벽/권한 설정은 바꾸지 않는다.
- 첫 실행 전 **가짜 누락·다른 경로/해시·잘못된 Windows PATH·운영 별칭 혼입**이 모두 가짜 본문/외부 도구 호출0으로 거절되도록 가드를 넣고 확인한다. 실제ssh가 호출되는지 확인하려고 실제ssh를 실행하지 않는다. 이후 정상/핀 불일치/보호값 거절/표준오류/빈 출력/SSH 실패를 합성 응답으로 새 고유 보존 경로에서 확인하고, 호출 횟수·종료값·미완료 표지·다음 호출 차단을 남긴다. 실패를 고친 경우 새 회차로 보존하며 성공 수를 합치지 않는다.
- 초안의 설치 상태 호출은rc0·stderr가 있어도 현재 다음 SQL 호출로 갈 수 있다. **설치 상태 읽기의표준오류/기록 실패도 다음 호출 전에 멈추도록** 같은 범위에서 보완하고 직접 경계를 확인한다. 생산용 초안과 시험 사본의 차이를 표로 남겨 사본 시험을 생산용 원문 검증으로 과장하지 않는다. 전체 실행기 최종 검토·운영 허가는 후속 제출에서 별도로 판단한다.

## 4. 지금 이어 갈 순서와 기존 일정

1. 사건/초안 보존 후 시험 가드를 먼저 보완한다. 남아 있는 로컬PG SQL·구동 명령·출력/종료값은 기존 파일에서 보존하고 없으면 미보존으로 적는다. 이를 채우기 위한 PG 반복은 하지 않는다. a1-pg는 이번 시험 전용이며 운영을 가리키지 않는 로컬 Docker context임을 확인할 수 있을 때만 종료/정리하고, 불명이면 보류한다. 가짜 경계 시험은 위 조건을 충족한 새 사본으로만 수행한다.
2. **소유 없는 행의 가능한 생성 경로 연결과11-24 18:00 A2·A3·D81 실행/복구 승인 묶음을 계속 완성한다.** 내용과 경계는 [v1.224 §3-1·3](../review-6c8111f9/README.md)을 따른다. A1 보완/검토 대기는 이 독립 작업의 중단 사유가 아니다. 과거 행 면제·가짜 등록·원문 사유 수정은 허용하지 않는다.
3. [v1.218 일정](../dec-launch-order-20261123/README.md)의11-25 배포 목표·11-27 중간 판정·11-30 최종S는 유지하되, 이번 사건을 읽기 실행 통제의 미해결 사항으로 인수표에 남긴다. 추가 읽기 전 해당 경계를 검토하며 날짜 때문에 관문을 완화하지 않는다. 고정1 단독과 DYNAMIC 병행 판단은 계속 구분한다.
4. 기존 승인된11-23 22:00 N03 회수는 취소하지 않는다. 고정read.sh(41e4f337)·회차당1회·중복 예약 확인·실제 시각/미관측 기록 범위를 유지한다. 가짜 시험의PATH·함수·환경을 이 운영 회수에 가져오지 않는다. 예약b2bd9036/22:14는 실제 목록/결과로 확인하며 총괄은 이번에 조회하지 않았다. 사용률 실제80% 확인 시 보존/대기, 미확인≠0%, 세션/PC 종료 중 자동 실행을 보장하지 않는다.

**최근 승인된 상태 읽기는10:36, 최근 실제 운영 호출 기록은이번 미승인13:07:50~13:08:05(PC)로 따로 적는다.** 사건을 빼고 마지막 읽기를10:36으로만 쓰거나 사건을 새 정상 관측으로 수용하지 않는다. 추가 A1/A2/A3·계좌/금액 조회, 배포/재기동·설정/감시 설치·자금 배정·생성/실전 시작은 승인 전이다. 권한 파일·비밀값·원시backend로그·캐시는 커밋에서 제외한다.
