# W3 설명 정정 (총괄 v1.134 §1·§3, 2026-11-07)

이 폴더의 README·콘솔·SHA256SUMS는 고치지 않는다. 이 메모는 SHA256SUMS 밖의 새 파일이다.

- run2 콘솔 `41/41`은 **단언 41개**다. run5 콘솔 `41/41`은 **단언 31개 + 관측 메모 10개**다(`note()`가 참을 결과에 더함). 두 실행을 합쳐 82건 시험이나 run5 단언 41건으로 세지 않는다.
- 56일 판정은 F5 SQL 조회 시각 주입이다. 앱 시계·데이터·서버 시각을 바꾼 시험이 아니며, 손절로 포지션이 이미 닫힌 뒤여서 56일 종료 시 보유 청산을 새로 검증한 것도 아니다.
- F3 거래소 KRW 차이 0.22는 ±1원 범위 안이다. 장부 `raw_diff=0.004`와 다른 값이다.
- 하네스 판정 보완(재시작 요청 HTTP 409 단언, F5 종료값·종료 시각 비교, 최고 평가액 대기 실패 시 중단, 환경 ERROR 예외 좁힘)은 다음 결과에서 순수 함수·가짜 입력으로 검증한다. 과거 출력은 고치지 않는다.
