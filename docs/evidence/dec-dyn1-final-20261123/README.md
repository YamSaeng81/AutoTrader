# 동적1 최종 제안안·운영자 확인사항·시작/종료 성과 포착안 — 총괄 v1.218 §3-5·v1.220 §3-3

2026-11-23 09:50 KST, 개발 세션 제출(총괄 판정 전, 11-24 기한). 기준은 [11-19 운용안 초안](../dec-ops-plan-20261119/README.md)(가상 자본)이다. 여기서는 사용자 확정 예산([v1.218 §1](../dec-launch-order-20261123/README.md), [budget.json](../dec-launch-order-20261123/budget.json))과 d81c3f2f 출처에 맞춰 값을 올린다. **운영 SSH·DB·계좌 조회, PG·빌드·시험은 하지 않았다.** 아래 금액은 모두 **제안**이다. 실제 배정, 계좌 현금, 등록표 cash_base, 생성/T0는 승인 전이다.

## 1. 전략·주기 — 11-19 사전 규칙 그대로

**제안: COMPOSITE_BREAKOUT H1**, 대안은 COMPOSITE_MOMENTUM_ICHIMOKU_V2 H1이다. 선정은 결과를 보기 전에 정한 ①~⑤ 규칙(REAL 생성 가능 → 다수 코인 설계 → H1 → 운영 경로 시험 연결 → 추세 이중 필터)을 따른다. 과거 최고 수익률이나 화면 성과로 바꾸지 않았다. BREAKOUT은 고정 가중(ATR 0.5·VD 0.3·MACD 0.2)이고 가중치 저장소를 읽지 않는다([비용 기준 조사](../dec-costbasis-20261119/README.md) 71행). 그래서 12월 중 다른 세션 결과로 규칙이 바뀌지 않는다.

## 4. 종료·중단 규칙

- 12-31은 첫 평가 시점이며 강제 청산하지 않는다. 열린 포지션은 평가에서 미확정으로 적는다. 계속/중단은 1월 첫 검토에서 정한다.
- 중단은 기존 정지 경로로 한다. **정지에는 청산이 포함된다**(미종결 매수 취소 → 보유 시장가 매도 → STOPPED). STOPPED만으로 완료 판정하지 않는다. SID203의 F2 명령은 재사용하지 않는다.
- 손실로 중단한 세션은 월 손실 여유가 남아도 재시작·입금 보충·증액하지 않는다(v1.218 §1).
- 12월 중 신호·필터·한도를 표본을 늘리려고 완화하지 않는다. 바꾸면 새 구간이며, 앞 손실을 지우지 않는다.
