## 2. pf3ok 보완(§3)

- 판정에 쓰는 R3 합계: 원가·매도 순대금은 `-?[0-9]+(.[0-9]+)?`, 수량은 0 이상 같은 형식만 받는다. `NaN`·`Infinity`·지수 표기·문자열·음의 수량은 종료3.
- 빈 칸(SQL NULL)은 그대로 허용하되 **개수 > 0인데 합계 NULL이면 판정 불가(종료1)**, 개수 0인데 합계가 있거나 원가 미상 수 > 체결 수면 형식 이상(종료3). 앞 판은 매도 순대금 NULL을 보지 않았다.
- 무거래 플래그는 `0`/`1`만. **플래그1 행도 형식 검사를 먼저 한 뒤에** 판정에서 뺀다.
- 파일 열기·UTF-8 해석 실패(CRLF 줄끝 포함)는 종료3. 오류 출력은 줄·열 번호만 내고 원문 값을 복사하지 않는다(시험·대역 출력에서 반례 값 0건 확인).
- 종료1 문구를 "진입 거절 예상"에서 **"보수적 사전 기준 미충족(비용 원천 사전 확인 기준, 제품 진입 결과라고 단정하지 않는다)"**로 바꿨다. R1/R2·조회문·위험 정책은 그대로다.

필수 기록은 순서대로 ① 미완료 표지 `out/INCOMPLETE.txt` ② 출력 시작 줄 ③ 원격 출력 ④ 끝 줄 ⑤ `out/exit-codes.txt` 완료 줄이다. 모두 성공한 뒤에만 표지를 지운다.

기록 실패 보고는 "원격 상태 미확인/부분, 확인·보고 전 재실행 금지"이며 자동 재시도는 없다. 원격 원문은 F+G+새 U변수+블록이고 마지막 문자가 `)`인 것을 다시 확인했다. 시험 1회차는 시험 스크립트의 위치 인자 덮어쓰기로 19건 뒤 중단해 결과로 쓰지 않는다([r1](runner/runner-selftest-r1.txt), 실행 틀 자체 실패는 0).
