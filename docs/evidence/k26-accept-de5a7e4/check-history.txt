총괄 검토 실행 이력(제품 시험 아님)
1. 원문 추출·해시·D2 12줄 차이·문법8개·판 표지/이미지 30입력은 첫 실행에서 통과했다.
2. 실행 틀 첫 대역은 실제 ssh 대신 Windows Git/bin/bash.exe 실행기로 가짜 ssh 스크립트를 호출했다.
   이 추가 실행기에 긴 서버 명령 문자열을 인자로 넘기며 Argument list too long/종료126이 발생했다.
   core-engine/build/k26-accept-de5a7e4/run-1 에 입력/출력이 남아 있다.
   추가 Windows 실행기를 없애고 같은 셸의 root_fake_ssh 함수(항상7, 인자 평가 없음)로 바꾸어 실행 틀을 다시 확인했다.
   이는 총괄 대역 장치의 문제다. 원문 run.sh·배포 블록·제품 코드와 기존 기대값을 바꾸지 않았다.
   실제 SSH 운송 성공을 이번 국소 확인으로 주장하지 않으며, 서버 실행도 없었다.
3. 문서 검사 첫 실행은 git diff 경로의 한글 파일명이 따옴표/8진수로 표시된 것을 실제 경로로 오인해 중단했다.
   git diff --name-only -z 의 원문 경로로 비교하도록 검사기만 고쳤다. 후보·문서·제출 파일을 바꾸지 않았다.
