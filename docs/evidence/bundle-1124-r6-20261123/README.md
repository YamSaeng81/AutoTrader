## 5. 남은 한계

- R6-1 관문은 **대상 포지션을 가리키는 남의 주문**만 막는다. 반대 방향(LIVE#203 주문이 남의 포지션을 가리킴)은 POS 금액에 섞이지 않아 이번 범위에 넣지 않았다. 그 주문은 `with_orders=true`일 때 MORD에 203 소유 행으로만 나온다.
- 관문 대상은 OPEN/CLOSING 포지션이다. 종결 포지션의 과거 연결 이상은 POS가 읽지 않으므로 거절 사유로 보지 않는다.
- 원격 STOP 흐름·서버 창 관문은 운영과 가짜 SSH에서 돌리지 않았다. 원문 순서 대조와 순수 함수 판정으로만 확인했다.
