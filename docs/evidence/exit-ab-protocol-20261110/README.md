## 집계기 규칙(결과 전에 고정)

- **순자산** = 현금 + Σ 열린 수량 × 평가가 × (1 − 0.15%).
  - 0.15%는 예상 청산 비용(수수료 0.05% + 모의 슬리피지 0.1%)이다.
  - 현금은 초기 자본에서 매수 현금 유출(수수료 포함)을 빼고 매도 순유입을 더한다.
- **평가 시각**: 시작 시각 + n일(n = 0..42)에 끝난 닫힌 M15 봉의 종가.
- **끝 가격이 없을 때**: 끝 시각에 열린 포지션의 평가가가 없으면 그 쌍은 판정 불가이고, 주지표도 판정 불가다. 그 쌍을 빼고 평균하지 않는다. 가상 청산이나 0으로 채우지도 않는다.
- **설정 거절**: 다음 중 하나라도 맞지 않으면 계산하지 않는다.
  - 정확히 4쌍 8세션이고, 쌍마다 A와 B가 하나씩이다.
  - A의 하한은 빈 값이고 B는 5다.
  - 쌍 안에서 전략, 코인, 주기, 자본, 비율, 상한, 시간 청산, 파라미터(실행 모드 포함), 코드, 시작·끝이 같다.
  - 구간이 42일이다.
- **구간 표시**: CODE_CHANGE, OUTAGE, COLLECTION_GAP 구간은 표시만 한다. 값을 빼거나 고치지 않는다.
- **진단**: 쌍 평균 (B − A) 일별 변화를 같은 달력 주의 모든 팔과 함께 복원추출한다(주 블록 부트스트랩, 2,000회, 시드 20261110). 90% 구간은 진단 값이며 통과 기준이 아니다. 일별 값이 하나라도 없으면 만들지 않는다.
