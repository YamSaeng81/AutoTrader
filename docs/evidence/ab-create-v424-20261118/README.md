## 1. 생성기 계약

- `--execute`에는 `--approved-date`(YYYY-MM-DD KST)·`--approved-c`·`--approved-t0`(시간대 있는 ISO)가 필수다. 비었거나, 시간대가 없거나, C가 M15 경계가 아니거나, T0≠C+15분이거나, C의 KST 날짜≠승인 날짜이면 **잠금·토큰·DB·POST 전에 2**로 멈춘다(기록부도 만들지 않음).
- 시작 시각의 경계가 승인 C와 다르면(다음 C·다른 날) 보내지 않고 2다. **첫 POST 직전과 매 POST 직전**에 다시 시각을 읽어 경계=승인 C이고 [C+6, C+12]인지 본다. 도중 이탈은 남은 팔을 보내지 않고 3이며, 기존 intent/result 기록과 대조를 남긴다. 초안 T0는 계산값이 아니라 승인 T0다.
- 실행 틀 STEP 2는 `AB_DATE`·`AB_C`·`AB_T0`가 없으면 `:?`로 도구를 부르기 전에 멈춘다. 이 경우 `2.rc`가 없어 STEP 3이 6으로 거절된다. 값을 steps.log에 남기고 그대로 넘긴다. SMA20(STEP 4)은 기존 날짜/창/T0 검사를 그대로 쓴다.
