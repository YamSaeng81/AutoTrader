## 5. 승인 경계·보존·월요일 인계

운영 배포·설치본/정기 점검/cron 교체·새 SQL/계좌 조회·토큰/POST·실제 생성/T0·실자금 시작·SSH 변경은 계속 별도 승인 전이다. 총원금·월 손실 상한·최종 동적 전략은 사용자가 정할 값이다. 로컬 구현 허용을 운영 실행 승인으로 해석하지 않는다.

W1~W6 코드·새 근거·본 지시 폴더·관리 문서3개는 기존 범위대로 커밋·일반 푸시할 수 있다. 권한 설정·인증·개인 사용량 기록·캐시는 제외한다. 도구 거절이면 우회하지 않고 해당 동작만 보류하며 구현 가능한 독립 작업은 계속한다. 총괄 검토에 올렸다는 이유로 다음 W항목까지 승인 대기하지 않는다.

11-23 08:00/08:30 인계에는 **W별 구현 파일·실행 결과·남은 입력/정책/권한·마지막 실제 N03 읽기·미관측 구간**을 적는다. 중간 보고는 다음 형식으로 충분하다: `W번호 / 방금 구현·검증한 것 / 실제 남은 경계 / 바로 다음 작업`. '전환해 주세요, 진행할까요'만으로 전체 작업을 끝내지 않는다.

이 문서는 새 작업 지시이며 구현 완료 보고가 아니다. 총괄은 이번에 W1~W6을 구현/시험하거나 운영에 접속하지 않았다. [문서 점검](document-check.json)·[체크섬](SHA256SUMS)은 지시서 파일의 보존 확인이다.
