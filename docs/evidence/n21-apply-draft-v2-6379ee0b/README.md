# N21 단독 적용안 v2 — 경계 보완 (총괄 v1.139 §107-1, 실행 금지)

**초안이다. 서버에서 아무것도 실행하지 않았다.** v1(`n21-apply-draft-6379ee0b`)은 고치지 않고 보존한다. 이 v2도 **Python-only 영향 검토용**이다. 실제 적용용은 O1·O3+N21 통합 초안 D3(`o1o3-n21-d3-b5cd1d0`)다. 총괄 결정대로 N21 단독 적용 뒤 옛 D2를 쓰는 순서는 쓰지 않는다.

### 그 밖에 바꾼 것

- **A2 기록 판정을 미확인으로 처리**
  - 시스템 기록이나 실행 기록을 읽을 수 없으면 미확인으로 멈춘다.
  - 시스템 기록의 inode가 바뀌었거나 줄 수가 줄면(회전 등) 미확인으로 멈춘다. 회전된 파일은 찾지 않는다(11-09 조사에서 `syslog.1`은 권한이 없었다).
  - 새 관측 행이 없어도 미확인으로 멈춘다.
- **A0도 같은 기록을 읽을 수 있는지 먼저 확인한다.** 못 읽으면 적용하지 않는다.
- **프로세스 패턴 `FPAT`은 명령줄 맨 앞이 python 실행 파일인 프로세스만 잡는다.**
  - 이 블록을 담은 bash 명령줄은 잡히지 않는다. 대역 프로세스 목록에 블록 원문 전체를 담은 `bash -c` 줄을 넣어 확인했다.
  - cron의 `/bin/sh -c` 껍데기도 잡히지 않는다. 그래서 python이 끝나고 껍데기만 남은 순간은 회차로 보지 않는다(v07).
- **바꾸지 않은 것**
  - 시간 창 :14~:24, A0 30분, 체크아웃만 하는 방식, 상태 파일을 되감지 않는 것은 v1과 같다.
  - 새 잠금·실행 기한·cron 변경·회차 강제 종료는 넣지 않았다.
- **PID·완료 식별자가 없어 시작 줄과 관측 행의 1:1 짝은 여전히 확정하지 않는다.** `at`은 재확인 회차면 재확인 뒤 시각이고, 아니면 1차 조회 전 시각이다. 완료 시각으로 쓰지 않는다.
