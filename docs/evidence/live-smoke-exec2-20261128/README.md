# 총괄 v1.257 — 실제 엔진 입력 보충 뒤 두 번째 시험

첫 LIVE#204는 실제 candle_data 최신성 부족으로 전략 평가 전에 막혀 매수0건으로 조기 정지했다. gate v4 PASS·BTC잔량0·KRW 원금 변화0이며, #204를 재시작하거나 기록을 지우지 않는다. 새 시도는 별도 세션·서버/로컬 폴더로 분리한다. 사용자 승인한 누적 매수대금+수수료1만원은 아직 소비되지 않았다.

## 입력 원인과 조치

1b719645의 LIVE는 candle_data를 읽고 CANDLE_LOOKBACK은500이다. 기존 U0/U3/U4의 BTC 입력 점검은 market_data_cache를 읽어 두 경로의 차이를 놓쳤다. 11-28 14:10 직접 집계에서 cache는 현재 H1을 갖고 있으나 candle_data는11-27 23:00 KST가 마지막이었다. candle_data 갱신은 백테스트용 일일 배치라 장중 LIVE의 지속 입력을 보장하지 못한다.

사용자의 진행 지시에 따라 기존 /api/v1/data/collect API로 BTC H1 11-28~11-29(종료일 배타·현재 거래소에 있는 봉만) 수집1회를 접수했다. 202를 완료로 보지 않았으며14:13 재읽기에서15행 증가, 마지막14:00·완료13:00 KST·최근24시간24개를 확인했다. 데이터를 임의 생성하거나 최신성 관문을 끄지 않았다. 제품·설정·cron·스키마는 변경하지 않았다.

이번 preflight/driver는 실제 엔진의 candle_data 최근500시간 최신 완료 봉·480개 이상·원시 결측2칸 이하를 생성 전에 추가 검사한다. 기존 자금/수수료/활성/기존 보유 검사도 유지한다. 공식 점검 예외를 임의 추가하지 않는다. 순수 입력12경계로 기존 조건과 세 신규 입력 경계를 확인한다. 실제/가짜 SSH·PG·제품 회귀/jar 시험을 반복하지 않는다.

## 실행

고정 v3의 HTTP/시각/기록·응답/DB 대조, 같은 관측기/stop1회·gate v4/BTC잔량 대조를 유지한다. 서버 전용 경로는 live-smoke-20261128-exp2다. 기존 exp1은 보존한다. 새 패키지 해시 고정 후 단일 서버 작업에서 신선한 입력 검사→P0→생성1회→verify→observer armed→start1회 순서로 진행하며, 실매수 정산 또는20분 기한에 정지한다. 조건 미충족이면 생성/시작하지 않는다.

이번 일회 수집은 장중 LIVE 입력의 지속 경로 수정이 아니다. 실제 테스트 결과와 별개로12-01 실전 전 LIVE 입력 공급/수집 경로의 지속 보완과 실제 엔진 입력을 보는 운영 점검이 필요하다. 이를 수익성이나 12월 시작조건 완료로 쓰지 않는다.
