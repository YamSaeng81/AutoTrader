## 4. 판단 대기 — 미래 관측 시각

- **현상(④)**: 관측 시각이 미래인 값 하나가 들어오면 장부가 그 코인에 대해 사실상 고정된다. 이후의 정상 값은 모두 "더 이른 관측"으로 버려지고, 고정된 값은 나이가 음수라 신선한 현재가로 쓰인다. 보유 시세 보강은 나이로만 대상을 고르므로 조회하지 않고, 재기동 전까지 자동 회복되지 않는다.
- **영향**:
  - 공유 풀 평가와 포지션별 한도(손실 한도 판정)
  - DYNAMIC 캔들 없는 회차의 손절·익절
  - 페이퍼 가정 체결가
- **발생 가능성**: 생산 경로는 거래소 체결 시각을 그대로 쓴다. 서버 시계가 거래소보다 늦으면 몇 초 미래 값이 생기지만, 그보다 늦은 정상 체결이 오면 덮이므로 고정되지 않는다. 고정은 거래소 시각 오류나 서버 시계 역행 같은 큰 편차에서만 생긴다. 운영에서 발생한 근거는 없다(조회하지 않음).
- **선택지**(새 허용 오차를 만들지 않았다):
  - (가) 장부에 적을 때 정렬·나이 계산용 시각을 `min(관측 시각, 받은 시각)` 으로 쓴다. 거절하지 않고 새 숫자도 없다. 관측은 수신보다 늦을 수 없다는 사실만 쓴다. 정상적인 몇 초 편차에서는 그만큼 '신선함'이 늘어나는 차이뿐이다. **권고.**
  - (나) 미래 허용 오차 X초를 넘는 관측은 거절한다. X 를 새로 정해야 하고, 정상 응답을 시각만으로 거절할 수 있다(지시상 금지 방향).
  - (다) 코드 무변경. 재기동이 유일한 회복 수단이라고 운영 절차에 적는다.
- 실시간 처리기에서 미래 시각 이벤트는 가격이 정상이면 그 가격으로 판정한다(그 틱 한 번뿐). 고정 문제는 장부에만 있다.
