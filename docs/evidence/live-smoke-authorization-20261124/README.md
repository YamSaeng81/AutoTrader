## 1. 허용 금액과 목적

- 우선 **시험 전체의 누적 매수대금 + 매수 수수료를 합해 10,000원 이하**로 해석한다. 주문당 10,000원씩 반복하거나 재매수로 회전시키는 허용이 아니다. 한 세션·한 종목·매수 1건에서 체결/정산을 확인하고, 보유분 매도·정산·종료 확인까지 한 왕복을 기본 범위로 준비한다. 매도는 확인된 보유수량 안에서만 한다.
- 기존 합산 예산 100,000원 안의 시험이며 추가 10,000원 입금 허용이 아니다. 실제 계좌 자금·수수료 여유와 미배정 상태는 확인해야 한다. 매도 수수료는 매도대금에서 차감하고 시험 비용에 포함해 보고한다. 10,000원은 투입 제한이며 시장 급변·장애 시 손실을 정확히 제한한다는 보장이 아니다.
- 목적은 실제 주문 제출→체결→잔액·수수료 정산→매도→종료·알림의 운영 경로 확인이다. 수익성 검증, 12월 본운영 시작, DYNAMIC 전략 확정 또는 반복 운용 승인으로 확대하지 않는다.

2. 수용된 비용 보호 수정이 운영에 배포되고 U2 이후 인수 확인까지 통과해야 한다. **기존 U0/U1 보류와 U2 직전 사용자 “재기동 진행” 확인은 유지**한다. 이 발언을 재기동 최종 확인으로 해석하지 않는다.
3. 실제 자금·기존 주문/보유·배정 충돌·손실 보호·중단/청산·알림 수신 및 대응자를 확인한다. A3가 보류인데 계좌가 충분하다고 쓰지 않는다. 원천이 더 필요하면 지정 열·호출 횟수의 최소 읽기를 제출한다.
