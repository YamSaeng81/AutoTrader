**A3 반올림 범위와 계좌 전체/시세 실패 구분은 준비 방향으로 수용하되, 현재 계산기와 월중·월말 실행안을 운영 판정용으로 수용하지 않는다.** 아래 §3의 실제 계산 공백만 보완한다. 추가 원천을 임의로 읽어 채우지 않는다.

## 3. 다음 로컬 작업 — 순서대로 이어 가며 11-24 18:00까지 제출한다

### 3-1. 수용한 U0를 실제 추출·실행 틀에 연결한다

현재 cd8bd76f의 extract.py·run.sh는 U0 **736351db**를 고정하고 있어 보정본 **91ea9342**를 거절한다. 보정 파일 하나를 둔 상태를 완성된 새 실행 출처라고 쓰지 않는다. 기존 폴더는 보존하고 새 경로에 **U0 교체·그 경로/해시·블록 목록·추출기/실행 틀의 고정값**만 연결한다. F·G·U변수와 나머지 7개 U블록은 바이트를 보존한다. 제품·SQL·pf3ok·OLD/NEW·JARN/JARM·관문·운영 호출 줄을 바꾸지 않는다. 11블록 전체를 새 고정 커밋에서 꺼내 해시를 대조하고, 최종 승인 목록은 그 출처를 가리킨다.

영향 확인은 **정상 새 출처 / 옛 U0 혼입 / 새 U0 변조**의 3경계만 한다. 정상은 명시적 파일 대역 1호출, 혼입/변조는 호출 0으로 거절돼야 한다. 가짜 시험은 [v1.225 §3](../review-a1-incident-20261123/README.md)의 환경 초기화·고정 절대 경로/해시·실제 SSH 대체 실행 없음·고유 보존 폴더를 적용한다. 생산용 전송 줄을 실제 SSH로 검증하지 않는다. 기존 기록 실패 계약은 코드 동일성과 앞 21건에 연결하고 9/21/27/201건·PG·회귀·빌드는 반복하지 않는다. 최종 커밋 SHA는 커밋 후 별도 제출 기록으로 고정해도 되며, 미래 SHA를 추측해서 넣지 않는다.

### 3-2. A3에서 시각·안정성 근거 없는 '충분'을 막는다

현재 a3calc.py는 DB 시각이 비어 있지 않은지만 확인하고 그 값을 비교에 쓰지 않는다. 저장된 c3는 계좌 호출 뒤 3초의 DB 값이며, 총괄이 이 DB 시각만 **2020년 또는 2027년**으로 바꿔도 둘 다 '충분'이었다. 축 관계·두 읽기 사이 안정성이 확인됐다는 근거가 아니다. t0 ≤ fetchedAt ≤ t1도 같은 시계라는 근거 없이 확정할 수 없다. 진행 주문·정리 대기·구간 이벤트 입력 누락을 기본 0으로 두는 처리도 운영 통과 근거로 쓰지 않는다.

새 사본 또는 명세의 필수 조건으로 **각 호출 전후 구간/시각 축 관계/비교 구간의 변화 유무를 확인한 원천과 범위**를 받는다. 근거가 없으면 해당 계산은 보류한다. DB `now()`를 정확한 스냅숏 시각으로 바꾸지 않는다. 세션 합 S의 대상과 자금 원천도 명시한다. RUNNING/CREATED만 더했다고 다른 상태의 배정 잔액이 계좌에 없다고 단정하지 말고, 실제 배정/회수 기록·잔액의 포함 범위를 확인하지 못하면 미배정 확정을 보류한다. 고정1 단독 시작에 병행 P7 완성을 새로 요구하는 것은 아니다.

새 파일 사례는 **시각 근거 불명 / 필수 진행·정리·변화 정보 누락 / 근거가 명시된 정상**의 3경계만 보충한다. 보존된 8건은 그대로 두고 새 기준에서 미확정으로 바뀌는 사례를 설명한다. 광범위한 형식 시험이나 새 계좌 수집기는 만들지 않는다. 정밀 KRW 원문 2열 읽기는 제안이며 여전히 승인 전이다.

### 3-3. 월 손실 식을 현금·예약·보유와 분리하고 최신 원천 계약에 연결한다

**`실현 손익 = available_krw − 배정 시작액`을 철회한다.** 매수나 예약 때문에 줄어든 현금은 그대로 손실이 아니다. 예를 들어 초기 20,200원에서 매수 대금 20,000원·수수료 5원, 남은 현금 195원·보유 평가 20,000원이면 순자산 손익은 **−5원**인데 이 식은 **−20,005원**을 낸다. 체결 전 현금 200원·남은 매수 예약금 20,000원이면 손익은 0이며 현금 식은 −20,000원이다. 현금 감소에 미실현 손익만 더해서는 이 차이가 복구되지 않는다.

- 기간 순손익은 기존 v1.218대로 **순자산 변화 − 외부 순유입**으로 대조한다. 순자산의 현금·미체결 잔여 예약금·보유 평가를 각각 정의해 중복 없이 합친다. 세션 배정/회수는 세션 경계의 자금 흐름이며 합산 시험 안의 내부 이동은 상쇄한다. 이를 거래소 입출금과 혼동하지 않는다. 부분 체결/환급/미정산이 있으면 기존 장부의 확정 여부를 따르며 임의로 원금을 복원하지 않는다.
- 실현손익 부분 합은 확정 매도 순대금에서 대응 매수 원가·수수료를 배분한 주문 원천으로 계산한다. 열린 원가/수량·확정되지 않은 수수료·시세를 0으로 채우지 않는다. 가용 잔액 식은 주문/보유/예약이 없고 배정·회수와 정산이 모두 확정된 조건에서의 보조 대조로만 쓴다.
- 누적 손실과 **최근 24시간** 순자산 변화의 기준 시점을 구분한다. 24시간 전 원천이 없으면 단계 시작 자산으로 대신하지 않는다. '−15,000원선이 먼저 걸린다'는 자동/확실한 집행 표현은 다시 철회한다([v1.219](../review-5ffde2e1/README.md)). 관측·사람 판단 중단이며 체결 손실을 보장하는 상한이 아니다.
- 최신 성과 경로는 **[변환기 v4·성적표 v5](../dec-scorecard-source-v4-20261120/README.md)와 [W4 R1](../weekend-local-fix-20261121/README.md)**다. 11-10 성적표 v2를 최신 원천 계약으로 인용하지 않는다. 파일·값·기준 시점·실제 읽기 명령/승인·부재 시 미확정을 표 하나로 연결하며 새 변환기나 제품 기능을 만들지 않는다.
- **12-31 23:30~23:50 조회는 경계 전 관측**이며 01-01 10:00은 경계 뒤 관측이다. 어느 것도 T=01-01 00:00 포착으로 이름 붙이지 않는다. [값별 불변 계약](../dec-scorecard-source-v3-20261120/README.md)대로 T 포착 또는 공백 전체를 덮는 값별 근거가 없으면 달력월 값은 미확정이다. 새 주문 0건만으로 기존 주문 수수료 정정·정산·잔액·가격이 불변이라고 판정하지 않는다. 실제 관측 기간 성과는 달력월 확정 합계와 구분할 수 있다. 경계 확정을 위해 거래 정지·56일 변경·이력 테이블 신설을 자동 착수하지 않는다.
