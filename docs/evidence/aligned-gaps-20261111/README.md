## 3. 보완 전 실패 재현 (경합 훅만 넣은 상태, `runs/race-before-fix.*`)

## 6. 남은 차이와 따로 보고할 경계

- **종전 PAPER 정지 0원 청산(제품 경계, 미변경):** 키가 없는 PAPER 세션은 정지 때 M1 캐시와 REST 현재가가 모두 없으면 0원으로 강제 청산합니다. 포지션 가치 전부가 손실로 기록됩니다. 사전 등록 66을 포함한 기존 PAPER에 해당하며, 66 경로를 바꾸지 말라는 지시에 따라 고치지 않았습니다. 운영 M1 캐시가 실제로 있는지는 이번에 확인하지 않았습니다.
