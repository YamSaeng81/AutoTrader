- 첫 국소 탐침은 285.0001의 기존 손익 계산(6자리 반올림)을 빠뜨려 기대를 잘못 세웠다. 이 가격은 실제 손절을 일으킨다. 판정 규칙을 바꾸지 않고 중간 입력을 285.00025로 고쳐 조기 점검/미발동 구간을 확인했다. 첫 소스·로그·결과는 `attempt1-*`로 보존했다.
- 첫 탐침에 알림 대역이 빠져 Telegram 전송 시도가 발생했고 HTTP404/재시도가 기록됐다. 성공 전달의 근거는 없다. 최종 탐침은 알림·웹소켓을 대역으로 고정하고 외부 자격증명 환경 항목도 제거했다. 거래소 주문은 두 번 모두 대역, DB는 두 번 모두 로컬 H2였다. 첫 탐침을 외부 호출0이라고 쓰지 않는다.
- jar 비교 자식 Python의 표준 출력이 cp949여서 첫 UTF-8 읽기는 실패했다. 원시 출력을 `*-raw.cp949.txt`로 보존하고 UTF-8 사본으로 변환해 제출 출력과 줄별 대조했다. 비교 코드와 jar는 바꾸지 않았다.
- `record.py.txt`는 일회성 문서 기록 스크립트다. 재실행하지 않는다.
