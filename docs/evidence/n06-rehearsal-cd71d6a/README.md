# N06 절차 인계 리허설 근거

- 임시 원본 S: `cd71d6ac052d94a44ff7f5c017a8ca8df8bf41dc`.
- 총괄은 기존 파일의 출처·해시·차이 한 줄을 읽어 대조하고 사본을 보존했다. 이번 보존 작업에서 시험이나 운영 명령을 실행하지 않았다.
- 이 폴더의 셸 파일은 **리허설 근거**다. 운영에서 직접 실행할 최종 인계본이 아니다. 최종 S는 11월 30일 운영 기준과 절차를 확인한 뒤 정한다.
- 원본 계획·OPS 문서는 Git의 S에서 복원한다. 문서 전체 해시는 `manifest.json`에 있다. 임시 폴더에 있던 파생 사본 9개는 원본 바이트 그대로 복사했고, 해시는 `SHA256SUMS`와 `manifest.json`에 남겼다.
- 계획 블록은 15개다. `4d4c5be` 대비 F 변수·F1 첫 블록 두 개가 바뀌었고 나머지는 13개다. 바뀌지 않은 OPS 블록을 포함하면 14개다.
- 새 기록 커밋이 생겼다는 이유만으로 S를 바꾸지 않는다. 새 S를 선택하면서 명령 블록이 같다면 SHA를 채운 두 실행 블록의 해시가 바뀌지만, 출처 SHA·문서 전체 해시·인계 기록도 따로 갱신될 수 있다. 명령이나 운영 기대값이 바뀌면 해당 블록을 다시 검토한다.
- 문법 검사 통과는 개발 보고이며 실제 cron 전환·F3·계좌 대조 실행의 증거는 아니다. 이번 검토를 이유로 이를 재실행하지 않는다.
