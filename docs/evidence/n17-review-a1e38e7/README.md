## 검토 실행 이력

`review.py`는 재현 가능한 검토 도구이며 제품/배포 블록을 바꾸지 않는다. 초기 검사에서 (1) 미추적 새 시험이 없는 `worktree.diff`를 전체 diff로 오인해 단언이 실패했고 운영 diff와 시험 소스 한계를 분리했다. (2) Windows 자식 stdout의 CRLF를 LF 텍스트와 비교해 실패하여 줄바꿈만 정규화했다. 검토 도구의 대조 조건 정정이고 제품 결함이나 앱 시험 재실행이 아니다. 최종 검토 결과는 `review.json`, 문서 불변 검사는 `doc-check.json`이다.
