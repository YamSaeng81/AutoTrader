### 411차 — G1 제출 경계·회복·음성 단언 (총괄 판정 전)

- G1은 **시험 읽기 결함**이다. 정지 목 응답 안의 시험 스레드가 정지 트랜잭션의 영속성 컨텍스트로 매도를 읽어, claim 전에 본 `INTENT_READY/null`이 접수 뒤에도 남았다. 같은 주문은 의도 커밋 → 커밋 뒤 접수 → claim → 거래소 대역 → `SUBMITTED`까지 끝났다. 원 시험의 단언 실패는 정지를 롤백시켰다. G1 상태의 폴러 철회 → 청산 확인 OPEN → 정리 작업 재매도 1회를 LIVE·DYNAMIC 직접 호출로 확인했다. 제품 변경 없음.
- LateOrder·N16 ③·N15Pg 정리 대기의 작업 전 통과를 게이트500으로 재현하고 장벽으로 보완했다. 고정 3f9cc926: 관련19클래스 게이트 없음 성공230·건너뜀4, 게이트50 성공218·건너뜀16, N15 실제 PG 6/6×2, 실패0. 대역이 없는 6클래스의 실제 WS 연결과 N15 PG ④의 정시 직전 시계 의존은 판단 대상으로 남겼다. N05 LIVE_ALIGNED K20~K23을 연결했다. [411차 근거](evidence/g1-submit-boundary-20261113/README.md)
