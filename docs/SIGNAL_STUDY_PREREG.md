## 0. 왜 이 실험인가

지금까지의 순서가 뒤집혀 있었다 — **"어떤 지표를 어떻게 조합할 것인가"가
"왜 이 조합이 비용보다 큰 수익을 낼 것인가"보다 앞서 있었다.**

"추세 지표 세 개가 동의하면 매수"는 **구현 규칙**이다. 여기에
① 어떤 시장 상황에서 ② 이후 가격이 얼마나 유리하게 움직이고
③ 그 움직임이 비용을 얼마나 넘는지에 대한 검증된 근거가 붙어야 전략이 된다.

573조합 실험이 보여준 것은 "이 14개 프리셋이 안 됐다"이지 "바탕 신호에 방향성이 없다"가 아니다.
이 실험은 그 아래 층 — **신호 자체** — 를 본다.

**성분 분해보다 이것이 먼저인 이유**: 진입/청산/필터 기여도 분해는 **전략이 존재함을 전제**한다.
바탕 신호에 드리프트가 없으면 0을 셋으로 나눈 결과만 나온다.

**청산 규칙 조정이 경로가 아닌 이유**: 2026-09-23 실측에서 승률이
추세추종 24~38%, 평균회귀(BOLLINGER/BTC) 56.8% 로 **정반대 손익 구조인데 기대값은 둘 다 0 근처**다.
가격이 해당 시간대에서 마팅게일에 가깝다면 손절·익절 조합과 무관하게 총기대값은 0이고 비용만 남는다.
**따라서 이 실험은 손절·익절을 두지 않는다** — 고정 보유기간으로 순수 방향 드리프트만 잰다.

## 3. 신호 정의 — 수식으로 고정

봉 t 종가 기준. `C` 종가, `O` 시가, `H` 고가, `L` 저가, `V` 거래량.

### 지표 계산 규약 (공통)

- **EMA(n)**: 첫 `n`개의 **SMA 를 시드**로, 이후 `EMA_t = α·x_t + (1−α)·EMA_{t−1}`, `α = 2/(n+1)`
- **Wilder 평활(n)**: 첫 `n`개 **합**을 시드로, 이후 `S_t = S_{t−1} − S_{t−1}/n + x_t`
- **표준편차**: **모집단**(n 으로 나눔)
- 🔴 **지표는 각 연속 구간에서 한 번만 초기화하고 이어서 계산한다**(§5).
  평가 시점마다 다시 시작하지 않는다.
- 모든 지표는 이 분석 스크립트에서 **독립 구현**한다

### S1 — MACD 히스토그램 0선 상향 돌파

```
MACD_t = EMA(C,12)_t − EMA(C,26)_t
SIG_t  = EMA(MACD,9)_t
HIST_t = MACD_t − SIG_t

신호 ⟺  HIST_{t−1} < 0  AND  HIST_t > 0
```

**정확히 0 처리**: 강부등호이므로 `HIST_{t−1}=0` 또는 `HIST_t=0` 이면 신호가 아니다.

> 근거: 모멘텀 가속에 단기 지속성이 있다.

### S2 — 강추세 + 장기 상승

```
신호 ⟺  ADX(14)_t > 25  AND  C_t > EMA(C,200)_t
```

**ADX 는 Wilder 평활로 독립 구현한다.** 저장소 구현은 단순평균이고 Wave 3-K 를 중단해 그대로다.
구현 결함이 원인인 귀무 결과를 만들지 않기 위해 **개념을 정확히 구현한 쪽**으로 검정한다.
⚠️ S2 결과는 운영 ADX 거동과 다르다. 이 실험은 시스템 검사가 아니라 **신호 검사**다.

#### 🔴 ADX 검증 — 통과하지 못하면 실험을 시작하지 않는다

**표준 Wilder ADX(14) 는 첫 값이 나오기까지 약 29~30봉이 필요하다**
(TR 은 직전 종가가 있어야 하므로 2봉째부터 → 첫 평활 TR/DM 은 15봉째 → DX 14개를 모아 첫 ADX).
**20봉으로는 산출 자체가 불가능하다.**

| # | 검증 |
|---|---|
| ① | **40봉 손계산 대조** — TR · +DM · −DM · 평활값 · +DI · −DI · DX · ADX 를 구현과 **독립적으로** 계산하고, **첫 ADX 와 이후 최소 3회의 재귀 갱신**까지 대조 |
| ② | **해석적 속성** — 고가·저가가 일정하게 상승하는 **지정 예제**에서 `+DI > 0`, `−DI = 0`, `DX = 100`, ADX → 100. 단조 하락은 대칭 (`−DI > 0`, `+DI = 0`) |
| ③ | **경계** — `0 ≤ ADX ≤ 100`; 완전 무변동 구간에서 `TR=0` 일 때의 처리를 명시하고 그대로 검사 |
| ④ | 저장소 기존 ADX 와의 **차이를 정량 보고** (검증이 아니라 참고 — 얼마나 다른지 기록) |

🔴 **`+DI = 100` 을 기대하지 않는다.** 고가·저가가 매 봉 1씩 오르되 봉 고저폭이 10이면
`+DM = 1`, `TR ≈ 10`, 따라서 `+DI ≈ 10` 이다. 그래도 `−DI = 0` 이므로
`DX = 100·|+DI − −DI| / (+DI + −DI) = 100` 이다.
`+DI = 100` 은 `+DM = TR` 이 되도록 **특별히 구성한 입력**에서만 성립한다.
검사는 `+DI > 0` · `−DI = 0` · `DX = 100` 으로 한다.

①은 **반드시 구현과 별개 경로로** 계산한다. 같은 오해를 두 번 하면 대조가 성립하지 않는다.

> 근거: 강한 추세는 관성을 갖는다.

### S3 — RSI 과매도 최초 진입

```
RSI(14) : Wilder 평활, 첫 14봉 평균 시드

신호 ⟺  RSI_{t−1} ≥ 30  AND  RSI_t < 30
```

30 미만이 이어지는 동안은 신호가 아니다.

> 근거: 과매도는 되돌린다.

### S4 — 볼린저 하단 이탈 후 복귀

```
MA_t    = SMA(C,20)_t
SD_t    = 모집단 표준편차(C,20)_t
LOWER_t = MA_t − 2·SD_t

신호 ⟺  C_{t−1} < LOWER_{t−1}  AND  C_t ≥ LOWER_t
```

이전 봉은 **강부등호**(확실히 이탈), 현재 봉은 **약부등호**(복귀 인정).

> 근거: 변동성 확장 뒤 평균 회귀.

### S5 — 거래량 급증 양봉

```
VMA_t = mean(V_{t−20} … V_{t−1})     ← 현재 봉 제외

신호 ⟺  V_t > 2.0·VMA_t  AND  C_t > O_t
```

> 근거: 자금 유입이 가격을 끈다.

## 4. 체결·수익·비중첩 선택

```
판정    봉 t 종가
진입    봉 t+1 시가       ← 판정에 쓴 종가에 체결한다는 가정은 쓰지 않는다
청산    봉 t+1+h 시가

r = (O_{t+1+h} − O_{t+1}) / O_{t+1} − c
```

| 항목 | 값 |
|---|---|
| 보유기간 h | **4 · 12 · 24** 봉 |
| 비용 c — **주 분석** | **0.30%** (수수료 0.05×2 + 슬리피지 0.1×2, **가격/포지션 기준**) |
| 비용 c — 스트레스 | 0.50% |

🔴 자본 기준 0.24%(= 0.30 × investRatio 0.80)와 혼동하지 않는다.

### 비중첩 선택

**(코인, 신호, h) 각각 독립적으로** 시간순 순회:

```
1. 첫 적격 신호 t₁ 채택
2. 이미 t_i 를 채택했으면, 다음 후보 t' 는  t' ≥ t_i + h
```

유도: `entry_{i+1} ≥ exit_i` → `t_{i+1}+1 ≥ t_i+1+h` → `t_{i+1} ≥ t_i + h`.
h 가 다르면 채택 집합도 다르다.

## 5. 🔴 연속 구간 · 워밍업 — v3 에서 전면 수정

### 지표는 구간마다 한 번만 초기화한다

**평가 시점마다 최근 N봉으로 EMA 를 다시 시작하지 않는다.**
연속된 과거 구간에서 한 번 시드를 잡고 **이어서 갱신**한다.

### 연속 구간(segment) 정의

직전 봉과의 시간 간격을 `Δ`(시간)라 하자. 정상은 `Δ = 1`, 결측 봉 수는 `Δ − 1` 이다.

| 조건 | 처리 |
|---|---|
| `Δ ≤ 6` (결측 봉 0~5개) | **같은 구간** — 이어서 계산 |
| `Δ > 6` | **새 구간** — 지표 재초기화 + 워밍업 재적용 |

**G = 6 의 근거**: 매 결측마다 구간을 끊으면 워밍업(700봉)이 데이터를 전부 잡아먹는다.
200기간 EMA 에서 6시간 이하 공백의 영향은 작다.

### 🔴 이 허용의 한계 — 결과에 명시한다

**"EMA200 에 영향이 작다"는 설명이 RSI(14)·ADX(14)·거래량(20)까지 정당화하지 않는다.**
결측을 건너뛰고 이어서 계산하면 이 단기 지표들은 **'시간' 기준이 아니라 '관측된 봉 수' 기준**이 된다.
`Δ = 6` 인 공백이 룩백 안에 들어오면 "직전 20봉 거래량 평균"이 실제로는 25시간을 덮는다.

이를 제거하지 않고 **측정해서 보고**한다(조건을 더 늘리지 않는다):

> 채택된 신호 중, 직전 20봉 안에 **허용된 공백(`Δ ≥ 2`)이 포함된 신호의 비율**을
> 조합별로 산출물에 싣는다(§10).

🔴 **이 비율이 작다고 영향이 미미하다는 보장은 없다.** EMA·Wilder 평활은 재귀적이라
**룩백 창 밖의 이전 공백 영향도 기하급수적으로 감쇠하며 남는다** — 직전 20봉만 봐서는
영향의 상한을 정할 수 없다.

따라서 이 비율은 **영향의 크기를 재는 값이 아니라 데이터 품질을 설명하는 지표**로만 쓴다.
비율이 크면 그 조합의 결과에 **명시된 한계**가 붙고, 작아도 "영향 없음"으로 읽지 않는다.
어느 쪽이든 **재조정하지 않는다.**

⚠️ `G = 6` 은 **판단이 개입된 선택**이다. 코인별 구간 수·길이·결측 분포를 산출물에 싣는다(§10).

### 워밍업 — 초기화 민감도로 정한다

🔴 v2 의 "EMA200 + 여유 50봉" 은 근거가 틀렸다. 평활계수 `α = 2/201` 에서

```
(1 − 2/201)^50  ≈ 0.607      ← 시드 차이의 61% 가 남는다. 수렴이 아니다
```

**1% 미만 잔존까지 필요한 갱신 횟수**:

```
n ≥ ln(0.01) / ln(1 − 2/201) ≈ 461
```

따라서 구간 시작부터 **200(SMA 시드) + 461 = 661**, 여유를 두어 **700봉**을 워밍업으로 버린다.

```
적격 봉 t  ⟺  ① 같은 구간 안에서 t 의 구간 내 인덱스 ≥ 700
              ② t+1 … t+1+h 가 모두 같은 구간에 존재하고 간격이 정확히 1시간
```

②는 **체결 연속성**이라 엄격하다 — 실제 체결을 모사하므로 결측을 허용하지 않는다.
①의 지표 연속성(G=6 허용)과 **층위가 다르다.**

**보고 의무**: 워밍업·결측으로 제외된 봉 수를 코인별로 싣는다.
제외율이 높게 나와도 **재조정하지 않는다** — 데이터 품질 한계로 기록한다.

## 6. 불확실성 — 패널 시간 블록 부트스트랩

### 쓰지 않는 것

- 🔴 **`유효표본 ≈ N/h`** — 등간격·특정 가정 아래의 근사일 뿐
- 🔴 **신호 행만 추린 Newey–West(lag=h)** — 표준 HAC 는 등간격 시계열 전제. 신호만 고르면
  "h시간"이 아니라 "h개 신호 간격"을 처리하게 된다

### 🔴 가짜 가격 경로를 만들지 않는다

블록을 이어 붙여 합성 가격을 만들고 거기서 지표·미래수익을 다시 계산하면 이음매에서 왜곡된다.

```
1. 원래 시간축에서  지표 → 신호 → 미래수익 → 비중첩 채택  을 전부 계산
2. 그 결과로 나온 **관측치**를 시간 블록 단위로 재표집
```

### 절차

| 단계 | 내용 |
|---|---|
| 1 | 연구 기간을 길이 `L` 의 **연속·비중첩 시간 블록**으로 분할 (블록 수 K) |
| 2 | 복제마다 블록 **K개를 복원추출** |
| 3 | 뽑힌 블록 구간에 **신호 봉 t 가 속하는 관측치**를 수집 — **13코인 동시에** |
| 4 | **신호군과 비교군을 같은 블록으로 함께 재표집** |
| 5 | 수집된 관측치로 통계량 재계산 |

4가 없으면 차이의 불확실성에 비교군 변동이 반영되지 않는다.
3이 코인 간 동시 상관을 보존한다.

| 항목 | 값 |
|---|---|
| 블록 길이 L — 주 | **72봉** (3일) |
| 민감도 | 24봉 · 168봉 |
| 복제 수 B | **2,000** |
| 난수 시드 | **20260923** |
| 신뢰구간 | **95% 백분위** (설명용) |

### 🔴 p값 — v3 에서 수정 (중심화 방식)

v2 의 `p = (1 + #{θ*_b ≤ 0})/(B+1)` 은 **검정 p값이 아니다.**
재표집 분포 `θ*` 는 관측 추정치 `θ̂` 주변에 분포하므로, 그 식은 분포의 음수 비율일 뿐
**귀무 아래에서 관측 이상이 나올 확률과 일반적으로 같지 않다.** `+1` 보정도 이를 해결하지 않는다.

**중심화 블록 부트스트랩을 쓴다:**

```
관측 통계량        θ̂
중심화 재표집      δ*_b = θ*_b − θ̂            (b ∈ 유효 복제)
단측 p값 근사      p = ( 1 + #{ δ*_b ≥ θ̂ } ) / ( B_유효 + 1 )
```

🔴 분모는 **유효 복제 수**다(아래 빈 표본 처리 참조). 전체 B 가 아니다.

`θ_절대` 와 `θ_기본대비` 에 **각각** 적용한 뒤 §8 의 IUT → Holm 으로 간다.

### 🔴 검정 크기(size) 점검 — 착수 전 필수

위 근사는 유한 표본·의존 구조에서 정확한 검정이 아니다. **위약(placebo) 신호로 오류율을 확인한다.**

| 항목 | 내용 |
|---|---|
| 위약 신호 | 실제 데이터 위에, 각 (코인, 신호, h) 의 **채택 신호 수와 비중첩 간격을 맞춰 무작위 배치** |
| 반복 | 500회 |
| 확인 대상 | **`p_기본대비` 의 기각률** — 위약은 비교군과 차이가 0 이므로 이것이 size 추정치다 |
| 판정 | α=0.05 에서 기각률이 **0.10 을 넘으면** 부트스트랩 설정(블록 길이 등)을 재검토한 뒤 착수 |
| 무효 복제 | **본 실험과 동일한 처리**(복제 전체 무효, `B_유효` 분모)를 적용한다 |
| 위약 편향 확인 | 위약군과 비교군의 **평균 차이가 0 을 중심으로 분포**하는지 확인 |

⚠️ `p_절대` 는 위약에서도 기각될 수 있다 — 시장이 비용보다 많이 올랐으면 무작위 진입도 양수다.
**그건 오류가 아니라 시장 드리프트이며, 정확히 그래서 ②(기본 대비)가 필요하다.**
`p_절대` 의 위약 거동은 **기술적으로 보고만** 하고 size 판정에 쓰지 않는다.

🔴 **이 기준이 뜻하는 것과 뜻하지 않는 것**

- **뜻하는 것**: 기각률 ≤ 0.10 이면 **사전에 정한 중단 기준을 넘지 않았다**
- **뜻하지 않는 것**: 오류율이 **충분히 통제됐다는 인증이 아니다.**
  명목 5% 수준이 검증된 것도 아니다. 0.05~0.10 사이여도 통과하며,
  그 경우 실제 유의수준은 명목보다 높다.
  통과한 조합의 p값은 **그만큼 낙관적으로 읽지 않는다.**

🔴 **위약 구성 자체의 편향을 확인해야 한다.** 무작위 비중첩 배치는 경계 효과 등으로
적격 봉을 **동일 확률로 선택하지 않을 수 있다**(예: 비중첩 규칙이 앞쪽 봉을 선호).
그러면 위약과 비교군의 기대 차이가 0 이 아니게 되어 size 추정이 무효가 된다.

🔴 **"0 과 유의하게 다르지 않다"를 쓰지 않는다.** 그것은 편향이 없다는 증명이 아니라
검출하지 못했다는 뜻일 뿐이다. **동등성(equivalence) 기준을 숫자로 고정한다.**

**(신호, h) 조합마다** 다음을 계산한다 (단위 %p, R = 위약 반복 수):

```
Δ_r   = mean(위약군 수익)_r − mean(비교군 수익)_r        r = 1 … R
m     = mean(Δ_r)
se    = sd(Δ_r) / √R
CI95  = m ± 1.96 · se
```

| 판정 | 조건 | 처리 |
|---|---|---|
| **통과** | `|m| ≤ 0.03` **AND** `CI95 ⊂ [−0.05, +0.05]` | 그대로 진행 |
| **판정 유보** | `|m| ≤ 0.03` 이지만 `CI95` 가 구간을 벗어남 | R 을 **2,000** 으로 늘려 재판정. 그래도 유보면 그 조합은 **NA(위약 편향 미확인)** |
| **실패** | `|m| > 0.03` | 위약 구성 결함. 고친 뒤 **전체 재점검**. 본 실험 착수 금지 |

**±0.03 / ±0.05 의 근거**: 최소 효과 크기 0.30%p 의 각각 10% · 17% 다.
이보다 큰 배치 편향이 있으면 합격 판정을 오염시킨다.

⚠️ 동등성 통과는 **편향이 0 이라는 증명이 아니라 ±0.05%p 해상도에서 유계**라는 뜻이다.

### 🔴 빈 표본 처리 — v4 에서 수정 (복제 전체 무효)

**동일 가중 대상은 점추정에서 확정된 포함 코인 집합으로 고정한다**(§9).

v3 은 "빈 코인은 그 복제에서 제외하고 계수한다" 였는데 **이는 대상 고정과 모순이다** —
발생률이 5% 이하라도 그 복제들은 **다른 코인 집합의 평균**을 추정하게 된다.
발생률을 기록하는 것으로는 해결되지 않는다.

| 상황 | 처리 |
|---|---|
| 복제에서 포함 코인 중 **하나라도** 관측치가 0개 | 🔴 **그 복제 전체를 무효 처리** |
| 무효 복제 비율이 **> 5%** (B=2,000 기준) | 그 (신호, h) 조합은 **NA(불안정)** |
| 무효 비율 **≤ 5%** | **유효 복제만** 사용. p값 분모 = `B_유효 + 1`, CI 도 유효 복제로 |

⚠️ **유효 복제만 쓰는 것도 조건부 재표집이라는 한계가 있다.**
"모든 포함 코인이 비지 않았다"는 사건에 조건부인 분포를 쓰는 것이므로,
무조건부 분포와 정확히 같지 않다. 무효 비율이 작을수록 차이가 작다.
**이 한계를 결과에 명시한다.**

🔴 **size 점검(§ 위)에도 동일한 무효 처리를 적용한다.** 그러지 않으면
점검한 절차와 실제 실행하는 절차가 달라져 오류율 추정이 의미를 잃는다.

조합마다 **무효 복제 비율**을 산출물에 싣는다.

BTC 잔차화는 **보조 분석**으로만 둔다 — 잔차끼리도 상관이 남으므로 상관 문제의 해법이 아니다.

## 8. 검정 수와 다중검정 — IUT + Holm

**주 검정 = 신호 5 × 보유기간 3 = 15개.** 늘리지 않는다.

```
p_조합 = max( p_절대 , p_기본대비 )
```

귀무가 합집합 `H₀: (θ_절대 ≤ 0) ∪ (θ_기본대비 ≤ 0)` 이므로 이는 **교차-합집합 검정(IUT)** 이고,
`max` p값은 두 성분에 별도 보정 없이 수준 α 를 통제한다.

- 15개 조합별 p값에 **Holm 보정**, 계열별 α = **0.05**
- 조정 전 p 와 조정 후 p 를 **둘 다 보고**

**CI 의 역할**: 개별 95% CI 는 **추정치 설명용**이다.
**다중검정 판정은 Holm 결과로만** 하며 CI 가 0을 넘는지로 판정하지 않는다.

국면 분할은 **탐색적 2차 결과**로만 보고하며 판단에 쓰지 않는다.

**①②를 모두 요구하는 이유**: ②만 보면 시장 상승을 신호의 공으로 돌리고,
①만 보면 조건을 건 것이 도움이 됐는지 알 수 없다.
