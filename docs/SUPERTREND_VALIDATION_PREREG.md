## 3. 🔴 불확실성 — 패널 시간블록 부트스트랩

**코인을 독립적으로 재표집하지 않는다.** 22코인은 같은 시장 움직임을 공유하므로
코인 단위 재표집은 불확실성을 **과소평가**한다.

### 🔴 거래 손익 합이 아니라 **자산가치 변화**로 집계한다

청산일에 거래 손익 전부를 넣으면 **여러 블록에 걸친 보유 손익이 마지막 블록으로 몰리고,
미청산 손익은 아예 빠진다.** 그래서 평가(mark-to-market) 자산곡선을 쓴다.

```
1) 코인·팔별로 **동일 시점의 일별 평가 자산곡선** E[coin, arm, d] 를 저장한다
       E = 현금 + 보유수량 × 그날 종가        (미청산 포지션 포함)
2) 일별 손익 변화율                r[coin, arm, d] = (E[d] − E[d−1]) / 초기자본
3) 검사 기간을 길이 L 의 연속·비중첩 **공통** 시간 블록으로 나눈다
       주 L = 30일,  민감도 14일 · 60일
4) 복제마다 블록을 복원추출 — **전 코인·전 팔에 같은 블록 집합을 적용**한다
5) δ* = 평균_코인( Σ_블록 r[coin,A,d] − Σ_블록 r[coin,B,d] )        ← **짝지은 차이**
6) B = 2000, 시드 20260924.  95% 구간과 중심화 단측 p값
```

4 가 **코인 간 동시 상관**을, 3 이 **시간 의존성**을, 5 가 **A·B 의 짝**을 보존한다.

🔴 **이 재표집은 "관측된 운용 성과의 불확실성" 분석이다.**
재배열된 시장에서 전략을 다시 운용한 시뮬레이션이 **아니다** — 블록을 섞어도 전략은
원래 시간축에서 내린 결정 그대로이며, 우리는 그 결과의 표집 변동만 본다.

(앞선 신호 실험 `SIGNAL_STUDY_PREREG.md` v5 §6 과 같은 구조다.)

⚠️ **평균·중앙값·15/22 개선 수는 서로 독립적인 증거 세 개가 아니다.**
같은 22개 값에서 나온 세 요약이며, **함께 봐야 하나의 판단**이 된다.

## 4. 🔴 판정 — 두 가지를 분리해 착수 전 고정

### (가) 변경안의 가치 — A 가 B 보다 개선됐는가

코인별 `순수익(A) − 순수익(B)` 에 대해:

| 조건 | 판단 |
|---|---|
| 평균 > 0 **AND** 중앙값 > 0 **AND** 개선 코인 ≥ **15/22** **AND** §3 구간 하한 > 0 | **A 로 변경할 근거 있음** |
| 평균 ≤ 0 **또는** 중앙값 ≤ 0 | **근거 없음.** A 변경안을 접는다 |
| 그 사이 | **판단 보류** |

### (나) 수익 후보 자격 — A **자체**가 비용을 넘는가

🔴 **(가)를 통과해도 A 와 B 가 모두 손실일 수 있다.** 그래서 따로 건다.

| 지표 | 주 비용 | 비용 스트레스(왕복 0.5%) |
|---|---|---|
| 코인 동일가중 평균 순수익 | **> 0** | **> 0** |
| 중앙값 순수익 | **> 0** | 보고만 |
| 양수 코인 수 | **≥ 12 / 22** | 보고만 |
| **거래당 순수익률**(아래 정의) | **≥ 0.10%** | **> 0** |

#### 🔴 거래당 순수익률의 분모 — 착수 전 고정

왕복 비용 0.30% 는 **가격 기준**(= 진입 포지션 금액 대비)이다. 비교하려면 분모를 맞춰야 한다.

```
왕복 거래 하나의 순수익률 =  (청산금액 − 진입금액 − 수수료 − 슬리피지) / 진입 포지션 금액 × 100
집계:  ① 코인별로 그 코인의 모든 왕복 거래에 대해 **단순평균**
       ② 그 코인별 평균들을 **동일 가중 평균**
```

🔴 `총수익률 / 거래 수`(= `PerformanceReport.expectancyPct`) 는 **초기자본 기준**이므로
이 기준과 **섞어 쓰지 않는다.** 두 값을 나란히 보고하되 판정은 위 정의로만 한다.

거래당 0.10% 기준의 근거: 주 비용 왕복 0.30% 의 1/3 — 비용을 넘고도 남는 최소 마진.
**자의적인 선택이며 착수 전에 고정했다는 데 의미가 있다.**

### 네 가지 결과

| (가) | (나) | 판단 |
|---|---|---|
| 근거 있음 | 충족 | **A 를 전향 검증(§5) 후보로** — 배포는 §5 이후 판단 |
| 근거 있음 | 미충족 | **A 의 상대적 개선은 관측됐으나 수익 후보 기준은 충족하지 못했다. 배포하지 않는다** |
| 근거 없음 | — | **A 변경안을 접는다.** B 유지 |
| 보류 | — | 판단 보류. 전향 검증에서 다시 본다 |

`B − OFF` 는 **판정에 쓰지 않고 보고만** 한다.

## 5. 전향 검증 — 종료 조건

🔴 **실제 검증 시작 시각(T0)부터** 생성되는 캔들로만 계산한다.
사전 등록일(2026-09-24)을 **소급 적용하지 않는다.** T0 는 세 팔이 모두 가동된 시점이며,
시작 후 이 문서에 기록한다.

**시간 방향으로 독립인 것은 이것뿐이다.**

### 시작 전 확인 — 셋

1. **T0 부터 새 자료로 계산한다** (위)
2. **코드·설정·코인·자본 배분을 고정**하고, 세 팔이 **자본도 전략 상태도 공유하지 않게** 한다
3. **공통 종료 조건과 수익 판정 기준을 유지**한다. 오류·위험 감시는 계속하되
   **중간 성과로 규칙을 바꾸지 않는다**

### 🔴 전향 검증 중에는 같은 전략의 가중치·필터를 손대지 않는다

검증 기간에 `COMPOSITE_MOMENTUM_ICHIMOKU_V2` 계열의 가중치·필터·임계값을 조정하면
고정한 시스템을 검증하는 것이 아니게 된다. **설명을 더 정교하게 만드는 작업을 멈추고,
고정한 시스템이 새 시장에서 비용을 빼고 남기는지만 본다.**

### 🔴 종료 시점 — 팔마다 따로 끝내지 않는다

```
종료 = min( 모든 팔이 각각 200거래를 채운 **공통 시점**,  6개월 경과 시점 )
```

| 6개월 시점 상태 | 처리 |
|---|---|
| 모든 팔 ≥ 200거래 (이전에 도달) | 그 공통 시점에서 판정 |
| 모든 팔 ≥ 100거래 | 그 시점까지로 판정하되 **표본 부족을 명시** |
| 한 팔이라도 < 100거래 | **판정 불가** |

### 중간 관찰 — 두 가지를 구분한다

| 허용 | 금지 |
|---|---|
| 운영 오류 감시 (체결 실패·데이터 결측·세션 중단) | **중간 성과를 보고 규칙·기준·팔 구성을 바꾸는 것** |
| 위험 감시 (한도 초과·비정상 손실) | 중간 결과를 근거로 조기 종료·조기 배포 |

위험 사유로 중단하는 경우 **그 사실과 시점을 기록**하고, 남은 자료로 판정하지 않는다.

## 6. 🔴 결과를 읽을 때

- **절대 순수익이 양수여도 수익 전략 확보가 아니다.** 앞선 Walk-Forward 는 이 계열 전략들을
  과최적화/불합격으로 판정했다
- **A−B 가 양수여도** 그것은 **상위봉 구성 방식**의 차이이며, Supertrend 의 방향 판별 능력을
  입증하는 것이 아니다
- 래퍼는 **BUY 뿐 아니라 SELL 도** 막고, 그 결과 포지션·청산 시점 → 호출 생략 → 내부 상태 경로로
  이후 신호까지 바꾼다. 결과는 **"배포된 래퍼와 엔진의 결합"** 의 효과로만 귀속한다
- **비개선·비유의 결과가 효과의 부재를 입증하지 않는다**

## 6.5 🔴 착수 전 회계 검증 — 먼저 한 코인으로

전체 실행 전에 **한 코인**으로 다음을 확인하고, 통과해야 22코인으로 확대한다.

| 검증 | 기준 |
|---|---|
| 일별 손익 합 = 최종 자산 변화 | `Σ_d (E[d] − E[d−1])` 가 `finalEquity − 초기자본` 과 일치 (반올림 오차 내) |
| 확장 전 러너와 동일 | 주 비용에서 `총수익률`·`거래 수`·`MDD` 가 `SupertrendFilterQ2Runner` 와 **같은 값** |
| 자산곡선 정합 | 마지막 시점 포지션이 0(엔진의 강제청산 후)이고 `E[마지막] = finalEquity` |

자산곡선은 **엔진을 고치지 않고** 거래 기록(`TradeRecord`: side·price·quantity·fee·executedAt)과
캔들 종가로 재구성한다 — 운영 코드 변경 없이 검증 가능한 경로다.

🔴 **이번 결과로 실전 운용이나 자본 확대를 정당화할 수 없다.**
