## 6. 막힘·일찍 완료·세션 중단 처리

1. 환경 오류면 정확한 명령/에러/영향 범위를 보존하고 다른 작업으로 전환한다. 같은 실패를 이유 없이 반복하지 않는다.
2. 최종 회귀에 실패하면 같은 입력의 원인 분석→최소 수정/격리→관련 범위 재검증 순서로 간다. 기점에서도 실패했다고 제외하지 않고 원인이 불명확하면 불명확하게 남긴다.
3. 현재 변경 경로의 보호 연결표·도구 입출력·복구 분기·시험 최종 SHA 연결에서 빠진 구체적 경계만 채운다. 새 전략 탐색/광범위 리팩터링/시험 건수 늘리기를 하지 않는다.
4. 허용된 작업이 모두 끝나면 완료/보류·다음 실제 읽기 시각을 남기고 대기한다. “밤새 작업”을 위해 같은 시험/네트워크 조회를 반복하지 않는다.
5. 이 문서는 실행 권한·작업 큐다. **세션 밖 영속 실행을 설치한 것이 아니다.** 세션 내 타이머를 사용할 수 있지만 세션이 끊기면 실행되지 않을 수 있다. 새 서버 cron/로컬 서비스/권한 우회로 감시를 설치하지 않는다. 중단 시 마지막 단계·후보 SHA·실행 중 명령/출력 경로를 체크포인트에 남기고 재개 때 완료 작업부터 다시 돌리지 않는다.
